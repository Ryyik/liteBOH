## 4. UI 手工测试脚本（需真实管理员账号）

> 探针假登录没有真实 JWT ⇒ RPC/RLS 会拒绝 ⇒ **审计写入与批量删除的「真实发生」只能在有账号的浏览器里验证**（§4.5）。其余功能假登录即可覆盖。

### 4.1 导出（A / S2）
1. 后台 → 数据管理 → 任意表 → 工具条「导出 ˅」→ 应出现两项：`导出当前页（N 条）` / `导出全部筛选结果（M 条）`，条数与页脚一致。
2. 点「导出全部筛选结果」→ 文件名含 `_all` 后缀；toast「已导出 M 条（全部筛选结果）」。
3. 审查点：`fetchAllFilteredRows` 每轮重建 query（`supabase/migrations` 之外的判据见 `tests/unit/data-admin-export-scope.test.js`）。

### 4.2 空状态三分支（A / S3）
1. 搜索一个不存在的词 → 「没有匹配的记录」+ 清除全部筛选，**无**「新增数据」。
2. 状态筛选选空值 → 「没有符合筛选条件的结果」+ 已生效条件摘要。
3. 真空表 → 「暂无数据」+ 新增按钮（有权限时）。

### 4.3 全选与批量（B / S1+S4，E / 真全选）
1. 勾第 2 行 → Shift 勾第 7 行 → 批量条「已选 6 项」；再 Shift 勾第 4 行 → 反选区间。
2. 全选本页（表头勾选）且总数 > 页内 → 批量条「已选 N 项（本页）」。
3. 批量条「删除」→ 单条/批量确认弹窗含「标识 / 归属 tab / ID / 关联类型 / 此操作不可恢复」；勾 ≥10 条时需输入「删除 N 条」，输错静默中止。
4. （E）「全选全部（M 条）」→ 批量条变「已选 M 项（按当前筛选，服务端执行）」→ 删除 → 富确认 → 服务端原子执行 → 结果面板「已删除 M 条」。**注意**：高级筛选激活时该入口不可用（设计如此）；users/points 两表无此入口（走 `admin_delete_user_account`）。

### 4.4 复制与快捷键（B）
1. hover 表格任意行 → ID/邮箱列出现复制按钮 → 点击 → toast「已复制」，剪贴板内容与单元格一致。
2. 按 `?` → 快捷键浮层；`Esc` 关闭；焦点回到触发前元素；**在文本输入框内按 `?` 不触发**；点过一个勾选框后按 `?`/`Esc` **仍**应生效（`2ba7b9f0` 修正点）。
3. `J`/`K` 上下移动行（表格视图，聚焦行勾选框 + 滚动跟随，空格勾选）。

### 4.5 审计链路（E，真实写入验证——关键）
1. 登录管理员 → 做一次删除（或导出/发放/审核）。
2. 日志监控 → 审计日志：应出现一条 `delete`（或对应 action）记录，含操作人/表/记录 ID；update 类记录的「变更摘要」列为 diff JSON。
3. 反向验证：用一个非管理员账号登录 → 审计日志 tab 应不可见数据（RLS 过滤）。
4. 失败降级验证（审查项「不阻断」）：构造 RPC 失败可用浏览器 DevTools 把 `log_admin_action` 请求 block 掉 → 再执行一次删除 → 删除**仍然成功**，仅 console 出现 `audit 审计写入失败` warn。

1. 存在待复核举报时，AdminHeader 下方出现「N 项需要处理 · 摘要」banner；正常时该元素**不渲染**（DOM 里搜 `admin-issue-banner` 应为 0 个节点）。

## 6. 审查陷阱（AI 容易误判的点）

1. **`@click` 不是 `@change`**：Shift 区间选择挂在 `@click` 上——`change` 是普通 Event 不带 `shiftKey`，改回 `@change` 会让区间分支静默失效（探针实测）。守卫：`data-admin-b-interactions.test.js` 断言 `not.toContain('@change="onRowCheckboxChange')`。
2. **部分暂存**：本批 commit 时对 `DataAdmin.vue` 做了「反向摘除并行补丁 → 暂存 → 还原」的部分暂存；review 单个 commit 时看到的是「HEAD + 本批」而非工作区全貌——工作区里并行会话的 P1-2/FocusTrap 改动**有意未提交**。
3. **lint-staged 重排**：pre-commit 会 prettier 重排 staged 文件（钩子会打印被改文件清单）——commit 的树 ≠ 提交前工作区，review 以 `git show <sha>` 为准。
4. **prettier 前置 commit**：`f5443f2d` / `cf4371e2` 是刻意的纯格式 commit（该文件历史版本未经 prettier，任何触碰都会被钩子整体重排）——用 `git diff -w` 或逐 commit 审可把语义 diff 隔离出来。
5. **doc-truth 计数口径**：`check:doc-truth` 数的是 `git ls-tree HEAD`（tracked），不是磁盘文件——工作区里并行会话的未跟踪文件不影响它。
6. **`DataAdmin.vue.orig`**：已移出仓库（gitignored 陈旧备份），它里面的「跨页全选」不算命中。
7. **旧单数表不存在**：`admin_audit_log`（单数）在线上从未存在过——旧直插一直在静默失败，这佐证了 E1 收口的必要性，不要误判为「删了已有的表」。
