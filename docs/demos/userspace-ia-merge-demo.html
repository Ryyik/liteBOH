「我」页三合一：空间 + 资产 + 印象

核心判断：这三个分段不是同一级的东西 —— 空间是「主页」，资产是「钱包」，印象是「别人怎么看我」。 把它们并列成三个 tab，等于逼用户为了看一句评价离开主页，也让「资产」这个低频事务占走了一个一级席位。 融合的主轴是：「我长什么样」归编辑资料，「我有什么」归主页一张卡，「我买过什么」归设置。

一、先看三个重复，这才是融合的真正理由 不是"页面太多"

积分出现 4 次 重复

hero 统计「1.3k 积分」/ 空间积分卡「1,280」/ 服务行「资产中心 1.3k 积分」/ 资产身份卡「1,280」。口径还不一致（1.3k vs 1,280）。

头像框有 2 个入口 重复

「编辑资料」里已经有头像框链接（截图 ④ 可见），「资产 · 装扮」里又是同一套 AvatarFrameGrid。同一个东西两处维护。

装扮 tab 只剩一项 空壳

「装扮」里原本有头像框 + 积分卡面。头像框既然已经在编辑资料，这个 tab 实际只剩「卡面」一个功能，却占着 1/7 的资产导航。

资产 7 个 tab 里 5 个是低频 失衡

概览 / 装扮 / 积分 / 订阅 / 订单 / 抽奖 / 赞助。真正每天看的是余额，其余是月级甚至年级动作，却和余额平级。

三、逐项迁移 8 条，每条都有落点，不留孤儿

原来在哪去哪动作为什么
资产 · 装扮 · 积分卡面 编辑资料 → 我的形象 搬 卡面和头像框一样是「我长什么样」。头像框已经在编辑资料里了，卡面跟着它走才一致。
hero 封面「更换背景」 编辑资料 → 我的形象 搬 背景同样是形象的一部分。三件形象资产（框 / 卡面 / 背景）在一处预览、一处保存。
资产 · 装扮 tab（整体） — 删 内容被上面两条搬空。tab 里只剩「更多装扮类型陆续上线」的占位文案。
资产 · 概览（余额 + 状态） 主页 · 资产卡 搬 余额是每天都看的东西，放主页比藏进第 4 个分段更合理。
资产 · 积分 / 订阅 / 订单 / 抽奖 / 赞助 设置 · 账户与资产（5 行） 搬 这五个都是月级/年级动作，和「账户与安全」「通知」同类。放进设置不会降低可发现性 —— 设置页本来就有搜索。
印象（独立分段 · 整页网格） 主页 · 印象条（一行）+ 展开看全部 升级 印象是社交证明，属于门面。藏进第三个 tab 等于削弱它；放主页一行反而更容易被看到，也仍然能点开看全部。
服务行「资产中心」 — 删 主页已经有资产卡，这一行是第四个积分入口。删掉后服务区只剩 Cloud+ / 摄影集两行。
hero 统计里的「积分」 — 删 资产卡就在下面，统计只留 发帖 / 粉丝 / 关注。顺带统一口径（都用 1,280 而不是 1.3k）。

四、这四张是真实截图 搬迁的起点和终点长这样

① 空间：hero + 活跃轨迹 + 积分卡 + 服务 + 内容。融合后除了删掉「资产中心」行和统计里的积分，其余原地不动。

② 资产：身份卡 + 7 个 tab。融合后这张卡的内容（余额）搬到主页，7 个 tab 全部下钻。

③ 印象：整页卡片网格。融合后压成主页一行摘要，点开才是这个网格。

④ 编辑资料：注意「更换头像 / 头像框」两个链接 —— 头像框已经在这里了，所以卡面和背景搬进来是顺势，不是新概念。

五、三个必须提前处理的风险

编辑资料会变长 中

从 4 个字段变成「形象 + 资料」两段。对策：顶部放实时预览（头像/框/卡面/背景四合一的小卡片），下面分两个折叠组，默认只展开「资料」。

老用户找不到卡面 中

原来在「资产 → 装扮」，现在在「编辑资料」。对策：深链 ?tab=assets 保留，重定向到主页资产卡并高亮一次；装扮页入口保留 30 天，点击直接跳编辑资料。

印象的删除按钮 低

主页一行里不该出现「删除」。对策：删除只在展开后的网格里出现（沿用现在的二次确认），主页摘要行纯展示。

工作量粗估：删分段（UserSpaceMain 的 SegmentTabs + contentSection）· 印象摘要行（复用 ProfileImpressionsPanel 的卡片，加 collapsed）· 资产卡（从 AssetsHubPanel 概览抽一个 AssetCard）· 设置加 5 行（复用 AssetsHubPanel 的 5 个 tab 组件）· 编辑资料加 3 个区块。前两项各约半天，后三项各 1 天左右。
