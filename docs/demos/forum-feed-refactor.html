A- 结构化白卡

看什么

1. 右栏 A- 的重点不是「变白」，而是卡片退到结构层：没有描边、阴影、模糊，靠页面底色和 20px 间距分组。 2. B 档把容器整个拿掉，靠 40px 留白 + 头像行锚点分段；滑到长列表里，需要人眼确认「还分得清一帖的边界吗」。 3. 顶部 tab 的胶囊底和竖线在 A-/B 里都消失了——它们是最容易看见的「噪音」。 4. 点「排版收紧」只改变字体层（字距 / 作者字重），不动容器：可以先单独判断这一项值不值得做。

不要从这个演示直接推结论

这是静态对照页，不是线上组件：图中的头像是字母兜底、图片是生成的占位图； 内容列固定 720px，用来让两档等宽可比 —— 真实论坛列更宽，行宽会更长； 正文截断用真实 max-height + 雾化省略号，但没接图片懒加载与虚拟列表。 真改之前要人眼看亮/暗 × 宽/窄四张截图，并跑 probe-forum-virtual-jump / probe-forum-viewport； 卡片高度常量在 useForumVirtualFeed.js:6（300px），改矮了必须同源改 spacer。
