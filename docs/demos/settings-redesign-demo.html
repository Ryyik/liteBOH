设置页改版：把「分组」从行里搬出来

对照 ChatGPT 那两页，我们的设置页差距不在皮肤，而在一行里塞了几件事。左边是线上现在的样子，右边是照它的骨架重做的一级页。下面四组开关可以随便切，看哪种组合是你要的。

总纲：一级页每行只承载「一个名字」。说明文字移到卡片下方的灰字脚注，行高从 76px 降到 44px，卡片左右内缩 16px —— 一屏能看全 6 个分组，不再需要「N 项」这个信息压缩徽标。

改后这张图上的四处改动

  1. 1搜索降级为圆角字段
    原来 38px 全宽吸顶条 + 下边框，现在 36px 圆角字段内缩 16px。能力不减，首屏少一条横线。
  2. 2账户降为卡片首行
    原来 64px 头像 + 昵称 + 邮箱独占 151px；现在 26px 小头像 + 名字 + ›，一行 44px。省下的 107px 正好装两个分组。
  3. 3行高 68 → 44，删「N 项」
    副标题移出行为卡片下方脚注（如「昵称、简介、头像与头像框」），计数徽标整体删除 —— 它只在双行结构里才有存在理由。
  4. 4危险区独立成卡
    退出登录不再挤在列表末尾，单独一张卡 + 红色文字。误触成本变高，视觉上也更像「这是最后一步」。

材质开关是这次真正的决策点，而它有个前提：背景里得有东西。把「背景」切到品牌主图再对比玻璃与平卡 —— 差别立刻出来；切回「纯灰（现状）」，两种材质几乎一样。这就是我们现在手机设置页的处境：页底是纯灰 #f5f5f7，卡片上的 backdrop-filter 写在 ≤767px 那一档还被整个去掉了，所以「液态玻璃」在手机上目前是失效的，只有桌面两栏才看得到模糊。换句话说：要么认清手机上它就是平卡、把 token 收干净；要么先把页底换成有内容的底再把玻璃救回来。这个开关就是让你在两个方案里选。
