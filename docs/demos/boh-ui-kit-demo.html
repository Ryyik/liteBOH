02

权重与配色 —— 用重量突出功能，不靠颜色堆砌

原则：屏幕上最重的东西只有一个。主操作蓝是稀缺资源——一屏只给一个 primary；语义色只表达状态，不做装饰。切换主题看同一套权重在暗色下的表现。

按钮四档权重

权重 = 视觉重量。越重的颜色越稀缺，primary 一屏一个。
Primary主操作 · 每屏一个
Secondary次操作 · 玻璃面
Ghost轻动作 · 无底
Danger破坏性 · 必弹确认
Loading任意档位内置

五类语义色

每类 = 实色（图标/边框/徽标）+ soft 底（标签/提示条）。全站只从这里取色。

配色纪律三条：① accent 永远不用于大面积铺底——它是动作色不是装饰色；② warning 不阻断、danger 必阻断（弹确认）；③ success 不抢戏——完成态用 soft 底就够，不需要动画庆祝。

浮层三兄弟

窄屏（≤560px）时「居中弹窗」自动变底部 Sheet——同一组件两种形态。

BOH 统一组件库提案 v0 · 2026-11-23 · 材质基因：src/styles/common/tokens.css（--liquid-* 单源拷贝，搬进 .vue 时删除本份、直接引用项目 token，否则 check:liquid-glass 门禁 fail）
落地顺序建议：Toast 统一 → BohModal/BohSheet → BohSpinner → EmptyState 补采用 → BohButton + token 更名。

BohModal · 居中弹窗

Teleport、遮罩、滚动锁、暗色适配、关闭按钮、窄屏自动变 Sheet——全部由组件内置。业务只写标题、内容和两个按钮。

BohSheet · 底部弹出

商城 11 个 Sheet、设置面板、分享面板——以后全是这一个组件。grab 条提示可下滑关闭（demo 里点遮罩关闭）。

BohConfirm · 破坏性操作

所有 danger 权重按钮强制经过这里。Promise 化 API：await 后才执行删除，取消就当无事发生。
