02

权重与配色 —— 用重量突出功能，不靠颜色堆砌

原则：屏幕上最重的东西只有一个。主操作蓝是稀缺资源——一屏只给一个 primary；语义色只表达状态，不做装饰。切换主题看同一套权重在暗色下的表现。

按钮四档权重

权重 = 视觉重量。越重的颜色越稀缺，primary 一屏一个。
Primary主操作 · 每屏一个
Secondary次操作 · 玻璃面
Ghost轻动作 · 无底
Danger破坏性 · 必弹确认
Loading任意档位内置

五类语义色

每类 = 实色（图标/边框/徽标）+ soft 底（标签/提示条）。全站只从这里取色。
Accent主操作 / 链接
#0071e3置顶
Success成功 / 在线
绿已完成
Warning需注意
琥珀待审核
Danger错误 / 破坏
红已封禁
Info中性信息
紫系统通知
配色纪律三条：① accent 永远不用于大面积铺底——它是动作色不是装饰色；② warning 不阻断、danger 必阻断（弹确认）；③ success 不抢戏——完成态用 soft 底就够，不需要动画庆祝。
