入口与回填

  • 发帖缩略图右上角 画笔角标 → 全屏进入编辑器
  • 确认 → 导出 ≤1600px JPEG → new File 替换 entry.file → 复用现有 压缩→审核→上传 管线
  • 取消 / 重置不产生任何变更，草稿无感

分层模型（非破坏编辑）

  • 底图 = 最长边 ≤2560px 工作位图，48MP 原图只在进入时解码一次
  • 五个工具全部是叠加层，坐标归一化 0~1，与分辨率解耦
  • 撤销 = 命令栈 diff，上限 30 步
  • 该纯数据结构可被单测全量锁死，渲染层做薄

接缝要点（已核对）

  • 编辑器会话归入 composer 闸门，不新增状态源
  • 「选图保持安静」口径不冲突（显式主动作）
  • 审核链零改动（含移动端跳本地模型的方案 A）
  • 重试读 entry.file，编辑后天然用新文件
