一、为什么是岛，不是下拉面板

归属面板是导航栏的延长，必须依赖导航栏存在；岛是独立悬浮物，可以挂在任何页面
状态语言面板只有开 / 关；岛的尺寸本身就是状态：胶囊＝待命，条＝可输入，大卡＝正在回答
几何耦合面板撑高要覆盖 surface 的 height，还要处理 mini caps、沉浸球；独立岛这些耦合全部消失
可用范围现在约四成路由没有导航栏，AI 直接不可用；岛 Teleport 到 body 后不存在这个问题

二、形态与尺寸（手机）

形态宽 × 高圆角内容
胶囊156 × 40999图标 + 「问一句」
输入344 × 52（含最近 140）26输入框 + 发送
结果352 × ≤ 34026第 0 项「问 BOHAI」+ 站内结果
回答352 × clamp(240, 可用, 480)30答案 + 来源 + 站内卡片

动画：宽度 cubic-bezier(.34,1.3,.64,1) 380ms（轻微回弹），高度 cubic-bezier(.16,1,.3,1) 460ms 且晚 20ms 起步 —— 先变宽，再长高。

三、意图路由

输入特征默认高亮理由
站内命中 = 0第 0 项没结果时唯一有意义的动作就是问
有命中，不像问句第一个结果与现状一致，零学习成本
有命中，像问句第 0 项问句给列表没有意义

判据：长度 ≥ 8 且含 怎么 / 为什么 / 能不能 / 帮我 / 是什么 / 在哪 / 哪个 / 吗 / ？。Enter 执行高亮项，⌘↵ 强制问 AI，Esc 逐层收回。

四、减法：岛内只留六件事

保留移回全页
输入 / 发送 / 停止模型与策略选择
流式回答（首屏 5–6 行）工具菜单（Cloud+ / 心理分析）
来源合并成一行 chip用量环 + 用量浮层
「引用本页」一颗 chip会话侧栏 / 新建 / 切换 / 改名
展开全文 / 去全页斜杠命令菜单
追问（同一输入条）赞踩 / 删除 / 跳转栏 / 复制整段

五、待拍板

1材质：深色岛（像 iOS，识别度最高）还是玻璃岛（贴站点风格）？现在是可切换的。
2落位：竖屏居中悬浮在导航栏下方，还是贴右下角（拇指可达）？
3手势：抓胶囊下拉展开（推荐），还是保留右边缘滑动、两者二选一？
