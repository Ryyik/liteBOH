## 2. 本批修复（3 项，均已验证）

### 2.1 顶部导航容器 `data-theme` 丢失（根因级，用户可感）

- **症状**：经 `/login`、`/join` 等 hideNavbar 路由往返后，顶部状态 toast「顶部动态导航已启用」、PityIsland / LabQuota 岛出现黑底黑字。
- **根因**：theme-manager 对白名单容器是**一次性命令式写** `data-theme`；导航容器被 hideNavbar 路由卸载再重挂载后，属性归空 ⇒ 所有 `#unified-nav-container[data-theme="dark"] …` 规则失效。页面容器用 `:data-theme="currentTheme"` 自管理所以无此问题——导航容器是唯一漏网的。
- **修复**：`src/components/UnifiedNavbar/index.vue:10`：bare `data-theme` → `:data-theme="currentTheme"`（单行，容器与页面同模式自管理）。
- **证据**：
  - 修复前全量 severe=**18**（2026-10-17 12:29，`/tmp/dark-audit-fresh.log`）→ 修复后 severe=**12**（12:40，`/tmp/dark-audit-results-final.json`）；
  - 插桩单页复测（`/tmp/probe-dark-audit-debug.mjs`）：user-space 页 `navTheme="dark"`、`#unified-nav-container[data-theme="dark"]` 深色规则 MATCH；
  - 修复后截图 `debug-screenshots/dark-audit-2026-10-17-us-posts-toast.png`：toast 暗色底浅色字正常。

### 2.2 八周年活动页整页未适配暗色

- **症状**：暗色模式下 `/#/boh-8-years-event` 整页白底浅卡（修复前截图 `debug-screenshots/dark-audit-2026-10-17-8years-event.png`）。
- **修复**：`src/views/BOH8YearsEvent/style.scoped.css` 末尾新增暗色适配块：
  - 全部只**消费**全局 `--boh-*` token（`themes/dark-mode.css` 在 `[data-theme="dark"]` 下换值），暗色块内零新增裸色字面量、零新增 `!important`（两条棘轮实测持平：2640 / 635）；
  - 主按钮/描边按钮用 `--8y-btn-*` 变量在亮色域定义、暗色换绑，实现「亮色=墨底白字 / 暗色=白底墨字」的反色；
  - 前缀用 `html[data-theme='dark']`（规避异步 chunk scoped + 暗色三坑①）。
- **跨页污染的中和**（根因见 §2.3）：UserSpace 全局 `.glass-card !important` 规则会压过本页一切背景声明，故在本页根上就地定义它消费的两个变量（亮色域 `--glass-bg-elevated: #fff` / `--glass-blur: var(--liquid-filter)`；暗色块内前者换绑 `var(--boh-bg-secondary)`），让全局规则解析回本页自己的材质 —— 不碰共享的 UserSpace 样式，零 `!important`。
- **验证**（三条独立路径，2026-10-17 实测）：
  1. 直接加载落定态：`.glass-card` computed 背景 `rgb(18, 18, 26)`（= `--boh-bg-secondary` 暗色值）；
  2. 复刻探针 24 页 SPA 行军（Profile 污染已就位的最坏路径）：中和前同路径 bg=`rgba(255, 255, 255, 0.8)`（污染复现），中和后同路径 bg=`rgb(18, 18, 26)`（✅）；
  3. 全量探针终轮（13:14–13:24）：boh-8-years 页 **severe 7 → 0**（唯一 warn 为 Little Skin 紫链 `#8b5cf6` on `#12121a` r=4.4，达标线上方，品牌链色）+ 截图 `debug-screenshots/dark-audit-boh-8-years.png` 肉眼过：整页暗色、白字清晰、主按钮反色为白底墨字。

### 2.3 跨页全局样式污染（根因级发现；八周年已中和，UserSpace 域待修）

- **现象**：boh-8-years 在探针连跑中稳定出现 7 条 severe（白字浅底，合成底 `#cececf`），但单页直载完全正常；shop「白卡间歇复现」（12:40 与 13:11 轮 4 条 `#9e9e9f`、13:00 轮 0 条）。
- **根因**（逐层定位，全链闭合）：
  1. `src/views/user-center/UserSpace/styles/profile-panels.css:721`：`.glass-card { background: var(--glass-bg-elevated, rgba(255,255,255,0.8)) !important; backdrop-filter: var(--glass-blur, blur(20px)) }` —— **非 scoped + `!important`**；
  2. 它由 `src/views/Profile/index.vue:38` 的**无 scoped `<style>` 块** `@import`（同块还引入 profile-base / shell-community / responsive-integrations 三张全局表）→ 访问过公开个人页后**常驻全站**；
  3. `--glass-bg-elevated` 在八周年页树上无定义 → 落到 fallback `rgba(255,255,255,0.8)` → 白色半透明卡叠暗色页 = 合成 `#cececf`（实测逐位吻合）；
  4. `!important` 压过一切普通声明：全局暗色表 `[data-theme="dark"] .glass-card`、本页 scoped 规则全部失效。
- **为何「间歇」**：污染只在 Profile chunk 注入后才存在；探针行军中 Profile(第9站)→shop(第10站) 紧邻，Profile 样式注入与 shop 页审计存在竞态——注入先到则脏（12:40、13:11），后到则干净（13:00）。boh-8-years（第25站）距 Profile 已远，注入必已完成 ⇒ 稳定复现。
- **已做的中和**：仅限八周年页（§2.2）。**UserSpace 域的共同道修复待做**（§4.1）：shop 的白卡、us-partners 的头像底同因。
- **探针取样等待顺带加固**：登录注入后 400ms→2000ms（`scripts/probes/probe-dark-audit.mjs`）。它与本根因无关，但消除了入场动画窗口的另一类取样方差（如 birthday warn 数 8↔11 的跨轮抖动），提升跨轮可比性；43 页成本 +~70s。
