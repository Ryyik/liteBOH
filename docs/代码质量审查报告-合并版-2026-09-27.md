## 五、对 C 报告的审查意见

### 判断准确、且是三份里独有的

1. **P1-1 `scoped @import` = 编译期复制且互相失效**（最有价值的一条）。Vue scoped 会把导入方的 `[data-v-X]` 加到共享 CSS 的每个选择器上 → N 份字节副本，且为 A 组件编译的那份**命中不了 B 组件的 DOM**。产物证据：`dist/static/css/DataAdmin-*.css` 中 `.g-*` 带 **12 个不同 scope id**，该 chunk 628KB 占全站 CSS 的 20%，而源文件只有 29.8KB。
   **这条链解释了 `!important` 的来源**——共享样式表静默不生效时，唯一奏效手段就是用 `!important` 硬穿。这是三份报告里唯一触及"为什么会有 1735 个 !important"的因果解释。
2. **P0-2 路由校验死代码**（见第三节，已实测复现）。
3. **P1-6 DataAdmin 拆法纠错**（见第四节，已实测复现）。
4. **改动频次 × 体量交叉**：`ForumMain`（4515 行 / 47 次改动）、`UserSpaceMain`（3115 / 45）、`DataAdmin`（6638 / 40）——"每次改动都在最难的地图上改"，这个论证比单纯排行数有力得多。
5. **"应当保留的优点"一节**：点名 `Lab/index.vue`（4650 行、**0 处 Supabase 直连**）应当作分层重构的模板，而不是待清理对象。这个反向判断很专业。

2. **`check:dark-tokens` 的 `dark-gate-scopes.json` `"strict": []` 为空**这条（P0-3），**2026-09-28 已核实属实并已修复**。`check-dark-tokens.mjs` 本来就有三档（strict glob 名单 / 总量观察=默认 / 总量严格=`--strict`），但 `verify` 与 `build:ci` 跑的都是**无 `--strict` 的观察档** → 暗色门禁当时确实永不阻断任何构建。

### 第 3 批：CSS 根因（唯一同时减体积 / 减 !important / 减"改了没反应"的一项）

15. ◐ **scoped `@import` 重复：报告这条是对的，但归因不全；已完成第一步（2026-09-28）。**
    报告只点了 `google-components.css`，实测**重复的主体是 4 个 partial**。正确口径：**不要数产物里的选择器**（各 partial 前缀不同、极易漏），直接数「每个 partial 被几个组件 scoped 导入」，`重复字节 = 体积 × (导入方数 − 1)`：

    | partial | 体积 | 导入方 | 重复字节 |
    | --- | --- | --- | --- |
    | base.css | 13,929 | 6 | 69,645 |
    | console.css | 41,643 | 2 | 41,643 |
    | **google-components.css** | 29,832 | **7** | **178,992** |
    | responsive.css | 30,544 | 6 | 152,720 |
    | overlays.css | 24,327 | 1 | 0 |
    | **合计** | 140,275 | | **443,000** |

    产物 `DataAdmin-*.css` = 641,924 bytes，而 DataManagement 源 CSS 只有 254,706 → **642KB 里 443KB（69%）是重复**。
    机制（报告说得对）：Vue 把 `[data-v-X]` 加到**元素自身**（实测 5633 处复合形态、**0 处后代形态**），所以 N 份字节副本、且父组件的副本匹配不到子组件内部的元素。

    **已做**：只修 `google-components.css`（它的 75 个顶层类**全部带 `g-` 前缀、0 个泛名** → 改全局不会泄漏）。
    - 做法沿用**仓库既有先例** —— `DataAdmin.vue` 的非 scoped `<style>` 块早已这样处理 `overlays.css`（那正是唯一 1 导入方、0 重复的 partial）：把它加进非 scoped 块、移除 7 处 scoped 导入、**保留** `main.js` 的延迟全局加载（有 3 个非 DataManagement 文件在用 `g-` 类）。
