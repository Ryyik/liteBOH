### 3.4 4.2 · Shift 区间选择

**位置**：`DataAdmin.vue` 的 `toggleSelect(item)`

**改为** `toggleSelect(item, event)`，内部维护 `lastSelectedIndex`（基于 `paginatedData` 的下标）：

```js
const onRowCheckboxChange = (item, event) => {
  const idx = paginatedData.value.findIndex((row) => getRowIdentity(row) === getRowIdentity(item));
  if (event?.shiftKey && lastSelectedIndex.value >= 0 && idx >= 0) {
    const [from, to] = [lastSelectedIndex.value, idx].sort((a, b) => a - b);
    const range = paginatedData.value.slice(from, to + 1);
    const shouldSelect = !isSelected(item);
    range.forEach((row) => {
      if (shouldSelect && !isSelected(row)) selectedItems.value.push(row);
      if (!shouldSelect && isSelected(row)) {
        selectedItems.value = selectedItems.value.filter((r) => getRowIdentity(r) !== getRowIdentity(row));
      }
    });
  } else {
    toggleSelect(item);
  }
  lastSelectedIndex.value = idx;
};
```

模板里所有行 checkbox 的 `@change="toggleSelect(item)"` 改为 `@change="onRowCheckboxChange(item, $event)"`（桌面表格 + 移动卡片 + 卡片视图三处）。

**验收**：勾第 2 行、Shift 勾第 7 行 → 选中 2–7 共 6 行；再 Shift 勾第 4 行 → 反选区间。

```sql
create index if not exists admin_audit_logs_table_time_idx
  on public.admin_audit_logs (resource_table, created_at desc);
create index if not exists admin_audit_logs_actor_time_idx
  on public.admin_audit_logs (actor_id, created_at desc);

alter table public.admin_audit_logs enable row level security;

create policy "admin can read audit logs" on public.admin_audit_logs
  for select to authenticated
  using (exists (select 1 from public.profiles p where p.id = auth.uid() and p.role = 'admin'));
```

RPC（security definer，**白名单 action**）：

```sql
create or replace function public.log_admin_action(
  p_action text,
  p_resource_table text,
  p_resource_id text default null,
  p_diff jsonb default null,
  p_meta jsonb default null
) returns void
language plpgsql
security definer
set search_path = public
as $$
begin
  if auth.uid() is null then return; end if;
  if p_action not in ('create','update','delete','batch_delete','grant','moderate','export') then
    raise exception 'unsupported action: %', p_action;
  end if;
  insert into public.admin_audit_logs (actor_id, actor_label, action, resource_table, resource_id, diff, meta)
  values (
    auth.uid(),
    (select coalesce(username, '') from public.profiles where id = auth.uid()),
    p_action, p_resource_table, p_resource_id, p_diff, p_meta
  );
end;
$$;
```

```js
export const logAdminAction = async (payload) => {
  try {
    const { error } = await supabase.rpc('log_admin_action', {
      p_action: payload.action,
      p_resource_table: payload.table,
      p_resource_id: payload.id ?? null,
      p_diff: payload.diff ?? null,
      p_meta: payload.meta ?? null,
```

## 9. 已知坑（踩过，别再踩）

1. **Supabase query builder 的 `.range()` 原地改状态**：循环分页必须每轮重建 `supabase.from(...).select(...)`，复用会拿到空数组或错位数据。
2. **`useDataAdminExport.js` 顶层 import supabase**：任何单测 import 它都会初始化客户端并可能因缺 env 抛错 ⇒ 纯函数放独立模块（`csv-export.js`）。
3. **后台主题不能独立**：`themeManager` 是唯一写入点。历史上另存 `localStorage['dm-theme']` 造成「站内选浅色、系统暗色时后台仍变暗」的 bug（`DataAdmin.vue:3618-3620` 有注释）。
4. **`hasActiveFilters` 包含 `searchQuery`**：用它判空必须先判搜索，否则搜索分支永远进不去。
5. **`totalRecordCount` 是含筛选的 count**：不能当「全表总数」用，也不能当「当前页条数」用（后者是 `paginatedData.length`）。
6. **新增 `src/` 文件会改 doc-truth 计数**：跑 `check:doc-truth:update` 并同步 `AGENTS.md` 三个数。
7. **抽组件后 lint 未使用符号**：迁走的 import 会留在壳里，每组 +2~5 warning，撞 114 上限。每抽一个 pane 跑 `lint:delta`。
8. **`role="menu"` 浮层要有键盘导航**：现有行操作浮层已支持 Esc/滚动关闭，新增菜单沿用同一套，别另写。
9. **审计 RPC 抛错会回滚业务事务**（若用触发器）：本方案走 RPC 且前端吞异常，不要改成触发器。
10. **`pinnedTabIds` 上限 8**：tab 溢出逻辑要按置顶顺序截断，别假设只有 4 个置顶。
