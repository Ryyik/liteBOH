### ❌ 判据错误：P0-2「AGENTS.md 超长行 ⇒ 被读取工具截断」

**这条是错的，不要照抄。** 原报告的判据是：

```bash
awk 'length($0) > 2000 { print NR }' AGENTS.md   # → 103、104、108
```

问题在**单位**：**macOS 的 awk 按字节计数**，而读取工具的截断线是 **2000 字符**。

实测（2026-10-15 复核，`git show HEAD:AGENTS.md`）：

| 行 | 字节数 | **字符数（码点）** |
| --- | --- | --- |
| 103 | 2406 | **1326** |
| 104 | 2214 | **1258** |
| 108 | 2209 | **1235** |

CJK 一字三字节，所以 2406 字节 ≈ 1326 字符。**全部在 2000 字符以内 ⇒ 从来没有发生过截断。**
（旁证：用读取工具实际读那几行，拿到的是**完整内容** —— 行尾是自然结束，没有截断标记。）

⇒ **教训与本仓库既有的那条完全一致：判据必须连「单位与口径」一起写下来。**
一个不带单位的 `length` 就足以编出一整条看起来很有说服力的结论。

### P0-2 · AGENTS.md 超长行 ⇒ 读取截断（AI 拿到的是残规则）

- 判据：`awk 'length($0) > 2000 { print NR }' AGENTS.md` → 行 **103、104、108**，最长 **2406 字符**。
- 主流 AI 文件读取工具对单行普遍按 2000 字符截断（本环境 Read 工具即如此）。
- 后果：这 3 行恰好是「改动 → 必跑门禁」表中 **BOH AI composer / 两胶囊 / 斜杠命令** 三个
  probe 链最长的条目，AI 读到的说明将在中途断掉，**事故记录（那些"已实测的坑"）正好落在截断区**。
- 该文件全文 214 行 / 51KB，信息密度已到"单行即一篇事故报告"的程度 ——
  对 AI 的上下文预算也是一次性拉满（首屏必读）。

### P1-1 · 门禁反馈链长 + 棘轮卡满 ⇒ AI 修复循环被迫拉长

- `verify` 全链 = lint(25s) + type-check(58s) + test(~184s) + 8 道 check + 棘轮总账 ≈ **4~5 分钟**；
  `verify:full` 再加构建与产物门禁（含 `compress-images` + `vite build` + bundle-size），**10 分钟量级**。
- **lint 棘轮恰好 116/116 无余量**：任何一次重构中留下的一个未使用变量立即 `exit 1`。
  AI 的典型行为是"先改中间态、后清理"，此棘轮对 AI 的失败模式**零窗口容忍**。
- 归因成本：棘轮是全局计数，AI 得用 `eslint . -f json` 做 set diff 才知道是不是自己新增的
  （MEMORY.md 已记载这一手法）——**没有现成脚本**（判据：`ls scripts/ | grep -iE "delta|doctor|env"` 为空）。
- 两道线上门禁（`check:db-lint` / `check:db-advisors`）需要 Management API token，
  AI 会话拿不到时**告警 + exit 0 降级**——设计上正确，但意味着"AI 在本地永远缺这两层反馈"。

### P1-2 · 根目录失控：规则明令"不再增加"，但 10-14 还在加

- AGENTS.md §6 明文：**"不要往仓库根目录新增 `xxx-demo.html`（已有 14 个是历史债，不再增加）"**。

- 另有 `repro-import-tmp.mjs` 落在根目录、`stats.html`（构建报告）。
- 结论：**这是一条没有牙的规则**——没有门禁、没有归拢目录，AI 每次做视觉沙盒"顺手放根目录"。

### P1-3 · 环境级坑共 10 条，全部成文但没有自动化自检

MEMORY.md「环境/工具」节记录、且经本次审计复核的坑：

| # | 坑 | 影响 |
| --- | --- | --- |
| 1 | `npx` 会被 SIGTERM | 所有 `npx xxx` 都得改 `./node_modules/.bin/xxx` |
| 2 | vite 只绑 IPv6（`--host ::`） | 探针/验收脚本连不上或连错 |

**问题不是"没记"——是记在按需通道（MEMORY.md），且没有 `env:doctor` 让 AI/人一键自检。**
每个新 AI 会话的"第一次踩坑成本"被反复支付。
