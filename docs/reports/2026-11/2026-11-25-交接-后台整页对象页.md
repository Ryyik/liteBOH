## 3. 六个「实测撞出来」的缺陷（全部已修，全部有守卫）

这六个都不是推理出来的，是浏览器实测/探针变红暴露的。**每一个都写了守卫，改回去必须变红。**

| # | 缺陷 | 症状 | 守卫 |
| --- | --- | --- | --- |
| ① | `:tab/new` 路由排在 `:tab/:id` **后面** | 新增页被通配吞掉，渲染成列表 | 断言 `:tab/new` 的 index < `:tab/:id` |
| ② | 判据用 `params.id === 'new'` | 静态段**不进 params** ⇒ 恒为 false，**且零报错**，静默掉回列表 | 断言用 `route.name`，禁止 `params.id === 'new'` |
| ③ | `isCreateRecordPage` 定义在首个使用点**之后** | **TDZ 整页白屏**：`Cannot access before initialization` | 断言定义 index < 使用点 |
| ④ | 列表 section 没排除新增态 | 新增表单下面接着「全部表 / 暂无数据」，**两页串成一页** | 断言 `data-console` 的 `v-if` 含 `!isCreateRecordPage` |
| ⑤ | 操作条 `position: sticky` | 被推出视口（`bottom=861 > 844`），五个按钮点不到 | 断言 `bottom <= clientHeight` |
| ⑥ | 删 `AdminSidebar` 的窄屏抽屉样式 | **四个控制台页侧栏失去定位、盖住内容连按钮都点不到** | `probe-admin-console-shell` 27 条 |

### 缺陷⑥要单独说明（跨组件隐式依赖）

`.g-sidebar` 是 `AdminSidebar.vue` 和 `AdminConsoleShell.vue` **共用的类名**。
`AdminConsoleShell` 靠 `AdminSidebar` 里那段 `@media` 给侧栏做 `position: fixed` 定位 ——
删掉之后，控制台页的侧栏变成普通静态块、盖住了汉堡按钮。

修法：给 `AdminConsoleShell.vue` 补回**它自己**的定位（+37 行），不再依赖别人。
**教训**：删共享类名的样式前，先 `grep -rn "该类名" src/` 看有几个消费者。

> 但注意 §6.1：改数字会改字节数，而余量是 0 —— 数字从 `726` 变 `729` 是同字节数，安全；

## 7. 关键设计决策（避免接手人「好心改错」）

### 7.1 为什么不给 `AdminSidebar` 加 `variant="page"`

我试过、也回滚了。原因：`AdminSidebar` 里有品牌区、搜索、页脚、折叠态等一整坨桌面语义，
加 variant 意味着每个子块都要包一层条件；而整页目录的层级（目录→组→内容）跟侧栏的
「分组+手风琴」是**两套结构**，硬塞进一个组件只会让两边都难改。

所以是**新建组件**（`AdminNavPages.vue`），只在 `isNarrowNav` 时渲染。
横屏继续用 `AdminSidebar`，两条路径互不影响。

### 7.2 断点判据是复制而非复用

`useAdminViewport.js` 里的判据（`min-width: 1024px` / `min-height: 600px` / `orientation: landscape`）
是从设置页 `useSettingsChrome.js` **抄过来**的，不是 import 复用的。

理由：设置页和后台的「什么算宽屏」未必永远一致（后台有表格，要更宽）。
复用一个常数会绑死两者。如果判定要改，两处都改 —— 这比「改一处把另一个页面搞坏」好。
（守卫里有一条断言「不能退化成 `innerWidth < N`」，因为那样手机横屏 844×390 会被误判进两栏。）

### 7.3 滚动恢复的两个时机都是试错出来的

| 尝试 | 为什么不行 |
| --- | --- |
| `onBeforeUnmount` 记位置 | 列表 → 详情**根本不卸载**（同组件复用），一次都没记到 |
| `watch(recordId 有→无)` 恢复 | 回列表时组件因 `:key="activeRoute.path"` **重建**，新实例拿不到「刚从对象页回来」这个信息 |
| 挂载即 `scrollTo` | 表格还没数据，可滚高度不够 ⇒ 被浏览器**夹小**（600 只能滚到 172） |

最终方案：`onBeforeRouteLeave` 记 + `onMounted` **消费式**读取 + 等 `hasLoadedOnce` 再滚。
实测 `600 → 600` 精确恢复。

### 7.4 三个 `EditDrawer` 实例共用一个 `editorBindings`

之前是两份 60 行的重复绑定，加第三个实例（新增对象页）会变成第三份。
上一次改字段就在 `@update-json-buffer` 上漏了其中一个 —— 这种重复必然漂移。
现在 props/事件只在 `editorBindings` 里写一份，模板只决定「用哪个形态、挂到哪」。

⚠️ 三者的 `v-if` **必须互斥**，同一时刻只挂一个，共享同一份 `editingItem`。
