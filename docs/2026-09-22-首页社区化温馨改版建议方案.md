# 首页社区化温馨改版 · 建议方案（v5 定稿）

> 2026-09-22 · BOHAI 🐾 · 五轮输入收敛：①街景开场、不放弃 hero 式 → ②参考 X、进来就是流 → ③清晰首屏 → ④满屏单 Hero + UserSpace/底栏归属 → ⑤**Hero 开场不再回归 + 官方 tab 收英雄流 + 底栏随论坛滑入**。
> 本文为最终方案。无 sticky、无回归动效，工程风险较前版进一步下降；现有 hero 排期内容 100% 原样保留（官方 tab）。

---

## 一、结论（TL;DR）

现状：首页 = hero 海报展示流（DB 排期），论坛藏在 `/user-space` 的 community tab。

**v5 终态四句话：**

1. **首屏 = 一个满屏 Hero（开场画）**：横竖屏 `100svh` 街景大图，图上只有时段问候 + 「往下逛逛 ↓」；**随滚动自然滚出，不再回归**——没有 sticky、没有收缩条、没有「回到街景」
2. **下滑直接进入论坛**：论坛是 Hero 下方的正常区块（顶部圆角分界），正常文档流滚动，无摘要、无快报
3. **论坛分区新增「官方」tab = 英雄流**：七分区（**官方** / 最新 / 关注 / 新闻 / 活动 / 成员 / 印象）——官方按用户要求排首位；「官方」= 现 hero 海报流**原样**（`home_heroes` 排期、渲染组件、弹窗全不动）。分区 URL `view` 单源自然扩展一个值；**默认分区仍为「最新」**（进来即帖子流不变；若要官方为默认落点，仅需改 `view` 默认值一行）
4. **滚到论坛时底栏滑入**：底部导航栏（方块街/消息/我的，全站同源配置）在 Hero 屏隐藏，IntersectionObserver 检测到论坛区可见后滑入；Hero 屏保持纯净沉浸

**UserSpace 归属**：论坛组件单源上首页 → UserSpace 移除社区 tab，收缩为 **我的 / 资产 / 消息 / 设置** 四 tab（个人中心，顺序沿用现底栏）；`?tab=community` 与 `/user-space/posts` 重定向 `/?view=latest`。

## 二、现状结构（代码事实）

- 首页 `src/views/Home/index.vue` = `HomeHeroRow` × N 渲染 DB 排期 hero（`DynamicHomeHero` / `BuiltinHeroRenderer`），归档区 + 页脚
- UserSpace `/user-space`（keepAlive）五分区（真源 `useUserSpaceTabs.js`）：**社区(community) / 我的(posts) / 资产(assets) / 消息(messages+AI) / 设置(settings)**
- 论坛分区（URL `view` 单源）：最新/关注/新闻/活动/成员/印象
- `UserSpaceBottomNav` 只在 UserSpace 内部；横屏切 `UserSpaceSideRail`；全站只有顶部 `UnifiedNavbar`
- 旧路由有成套 redirect 先例

## 三、依据（调研要点，浓缩）

- **FeverBee / Vinfotech / UX Magazine**：首页为老成员服务、回答「此刻社区在聊什么」、Who's New 提升留存、activity feed 仪表盘化
- **X**：进来即流；分区 tabs 切换——「官方」tab 即 BOH 版内容通道
- **2026 warm UI 趋势**：暖白低饱和、soft minimalism、慢微交互、`prefers-reduced-motion`
- **Yuushya Townscape**：叙事文案、成员署名、场景标签——「走进街里」隐喻

## 四、页面规格

### 4.1 首屏：满屏 Hero 开场画
- `100svh`（横竖屏一致，`svh` 防地址栏抖动）；**正常文档流第一屏**，滚动即自然离开——不吸附、不回归、不收缩
- 图上两层：时段问候（构图留白区）+ 底部「往下逛逛 ↓」呼吸提示（首次滚动后淡出）
- 不叠任何数据/按钮；快报数据只在桌面右栏「正在发生」
- 图源：`home_heroes` 新增 `street-scene` 模板；横/竖双构图（`matchMedia('(orientation)')` 切换）
- LCP：单图 WebP/AVIF + `fetchpriority="high"` + 骨架占位（扩展 `home-hero-loading`）
- 离场后停渲染：IO 检测 Hero 完全离开视口 → 图片卸载/暂停（回滚到顶恢复）

### 4.2 下滑直达论坛
- 论坛区 = Hero 正下方的正常区块，顶部以 20-24px 圆角 + 描边做「纸片」分界（纯样式，无覆盖/吸附行为）
- 进场轻 reveal（fade + 24px 上移，IO once，包 `prefers-reduced-motion`）
- 分区 tabs + 帖子流 = 现有论坛组件单源复用，分区数据与过渡（`userspace-tab-in/out`）机制原样；分区排序调整为官方居首（用户指定），其余顺序不变

### 4.3 「官方」tab = 英雄流
- 分区 tabs 首位「官方」（用户指定排序：官方 / 最新 / 关注 / 新闻 / 活动 / 成员 / 印象），`view=official`
- 选中时渲染 **现有 hero 流原样**（`HomeHeroRow` 循环 + `DynamicHomeHero`/`BuiltinHeroRenderer` + 各弹窗），排期/显隐/归档机制零改动；运营心智不变
- 惰性挂载：首次切到「官方」才加载 hero 渲染层（不进首屏壳）；keepAlive 缓存已访问过的分区
- 分区单源机制不变：只是 `resolveSectionFromRoute` 的合法值多一个 `official`，渲染分流到 HeroFlow
- 帖子/英雄的跳转入口：Hero 屏呼吸提示下方可留一枚「本周海报 →」直达 `view=official`（可选）

### 4.4 底栏：滚到论坛自然滑入
- 底栏 = 全站同源组件 + 配置真源（`src/config/bottom-nav.ts`）：首页 items = **方块街 / 消息 / 我的**；UserSpace 内 items = 四 tab（同源配置不同组）
- 显隐规则：IO 监听论坛区可见性——Hero 屏隐藏（`translateY(100%)`），论坛区进入视口 → 滑入；滚回 Hero 屏 → 滑出。动画 250ms，包 `prefers-reduced-motion`（直显直隐）
- 桌面/横屏：首页不挂底栏，靠顶部 UnifiedNavbar + 可选左栏（SideRail 模式承接「正在发生」）
- 未登录：首页公开页——帖子流展示公开内容 + 「登录后互动」；上线前按 pg_policy 复核 anon 读权限（不回退 anon-execute 基线）

### 4.5 UserSpace 收缩与重定向
| 变更 | 内容 |
|---|---|
| 移除社区 tab | 四 tab：**我的 / 资产 / 消息 / 设置**（顺序沿用现底栏，去掉社区即可；真源 `useUserSpaceTabs.js` 的 `userSpaceNavItems` 删一行） |
| 重定向 | `?tab=community`、`/user-space/posts` → `/?view=latest`（沿用既有 redirect 模式，保留其余 query） |
| keepAlive | `/user-space` keepAlive 不变；论坛组件迁出后其缓存随之迁移 |

**UserSpace 底栏变化清单（5 → 4）**
- **移除**：社区 tab（label 实为「社区」，即论坛容器；组件与数据源整体迁首页「官方」tab；`useUserSpaceTabs.js` 的 `USER_SPACE_VALID_TABS` 与 community 懒挂载分支同步移除）
- **保留**：未读徽标、hover/focus 预载、横屏切左栏（SideRail）、tab 过渡方向与滚动位置记忆、设置-编辑资料态整条隐藏、AI overlay 态
- **同源**：`src/config/bottom-nav.ts` 三处共用（首页 / UserSpace / 后续页面），未读数同一 store——首页底栏的「消息」同样亮红点
- **收尾**：IA 探针基线更新（tab 数变化会改布局断言）；滑动指示器 `navIndicatorStyle` 间距自适应无需改逻辑

**第 4 席评估记录（结论：保留「设置」）**
- 四席定稿 = **我的 / 资产 / 消息 / 设置**。设置面板是近期高触达功能的枢纽（通行密钥、推送/Pushplus、账户安全、版本 Beta、编辑资料入口），随功能迭代使用频率在上升，且零迁移成本
- 排除 **Cloud+**（`/user-space/note`）：受众相对窄、已有独立入口，放「我的」页快捷卡即可，不值得占底栏
- 排除 **BOH AI**：2026-09 IA 刚把 AI 并入消息 tab（`消息(+AI)`），再拆出来是 IA 倒退
- 排除 **树洞**：它是 BOHAI AI 的记忆体系（`treehole-space-api` / `memory-api`），不是独立社区功能，没有 tab 形态

### 4.6 节日特别模式（保留，P2）
排期行开启 `fullscreen` → Hero 变全屏引导式逐幕（v2 六幕），周年庆/大活动彩蛋；与「官方」tab 共用同一套 hero 渲染层。

## 五、温馨视觉语言（token 级）

1. 底色暖化：亮色页底 → 暖白 `#FAF7F2` 系；暗色对应暖炭色；只动 `tokens.css` 页面底色，**不碰 `--liquid-*` 单源**
2. 6:3:1：品牌色 CTA 10% + 低饱和暖点缀（珊瑚/杏/苔绿）30% + 主体暖白 60%
3. 论坛纸片顶角 20-24px；流卡片 16-20px 圆角、间距 12-16px；官方 tab 海报卡保留现有视觉（「原样」承诺）
4. 微交互（呼吸提示/底栏滑入/reveal）全包 `prefers-reduced-motion`
5. 空态：`EmptyState.vue` + 街坊文案；改材质重跑对比度

## 八、工程门禁与风险

1. 改首页骨架必跑 CI 全链（views → structure → liquid-glass → important-budget → first-paint → build → shell-precache → bundle）；流数据不进 SW 预缓存壳；hero 渲染层与论坛组件均异步加载，不进首屏壳
2. **无 sticky 方案的红线只剩两条**：统一导航 fixed 的 z-index 层级实测；移动端 `svh` 实测
3. 官方 tab 惰性挂载与 keepAlive 组合：首次切换的加载态要有占位（沿用 `home-hero-loading` 骨架），避免白屏感
4. 暗色一致性走 `theme-manager.js` 13 容器白名单；新 `!important` 登记 important-budget
5. 反证验证（Playwright 探针）：满屏 Hero 默认态、滚动自然离开且停渲染、七分区含官方、官方渲染 hero 流且弹窗可用、深链 `/?view=official` 直达、底栏随论坛滑入/滚回隐藏、redirect 生效、reduced-motion 降级、未登录公开内容
6. 风险：树洞一句匿名不可定位；成员投稿署名授权默认值；UserSpace 移除 tab 后跑 IA 探针基线（79 PASS / 1 既有 FAIL）对照；`view=official` 与现有分区值命名冲突需先查 forumData 分区表
