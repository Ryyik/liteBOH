## 2. 三条铁律（两次「白底隐形」事故的教训，违反 = 事故复发）

1. **观感参数只改 `src/config/liquid-glass-spec.js`** —— 组件 props / CSS 令牌 / 壳钳制 /
   滑杆边界全部引用它，**禁止写死第二份数值**；改完必跑
   `npx vitest run tests/unit/bohai-glass-look-spec.test.js`。
2. **玻璃模式只撤实底，禁止撤投影与边框** —— `box-shadow: none` /
   `border-color: transparent` 在折射级 `@supports` 块里被守卫禁止。白底上玻璃的
   轮廓识别全靠这两样（两次事故的直接死因：厚膜 + 撤投影）。
3. **采样根**：玻璃祖先链上不得有堆叠上下文（z-index / isolation / opacity<1 /
   filter / transform / mix-blend），直到第一个「包含背景内容」的根（如 `.boh-main`）。
   ⚠️ 堆叠属性的 A/B **必须整页重建对比** —— 运行时改样式不触发重合成（假绿/假红）。

## 3. 技术硬约束（每条都有实测事故记录，详情 §21.7）

- 覆盖层结构：`position:absolute; inset:0; pointer-events:none` +
  `glassSize:{width:'100%',height:'100%'}`；原 DOM / 交互 / 探针选择器零改动
  （回滚 = 删宿主里的锚 + 玻璃组件）。
- `elasticity` 恒 0（漂移会让输入框/浮层误点）；只用 `standard` 模式（免 shader worker）。
- 裸 JS SFC **禁 `withDefaults`**（dev server 当场 500）。
- 菜单类：锚承载定位（`bottom: calc(100% + 8px)`），**v-show 留在菜单本体** ——
  挪到锚上会让既有探针的 `display` 断言全假。
- 玻璃实例预算 ≤6/页（每实例一个 SVG filter）。
- 新面必配「采样根」断言（照 `probe-bohai-glass.mjs` 复制）。
