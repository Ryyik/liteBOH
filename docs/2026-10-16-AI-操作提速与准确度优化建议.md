## 0. 结论速览

1. **大部分环境坑已经有防线**（AI-ENV §3 + env:doctor + 门禁），本方案不重复建设；
2. 真正的增量在四处：**① deno 本地化后的"编辑器内类型反馈"**、**② 一个配置文件服务全部 IDE**、
   **③ 仓库里两处小噪声（supabase/.temp、.trae 待裁决）**、**④ 双实例协作纪律**（今天事故的教训）；
3. **明确不做**：不引入新工具、不重写 git 历史、不建重型新脚本 —— 高成本低收益的都不做。

### 3.2 的整段配置（直接粘贴到你本机 settings.json）

```jsonc
// 搜索与文件监听排除（编辑器索引提速）
"search.exclude": {
  "**/node_modules": true,
  "dist": true,
  "dist-check": true,
  "debug-screenshots": true,
  "coverage": true
},
"files.watcherExclude": {
  "**/node_modules/**": true,
  "**/dist/**": true,
  "**/dist-check/**": true,
  "**/debug-screenshots/**": true
},
// Edge Functions 走 Deno 语言服务（配合 3.1 的扩展；前端不受影响）
"deno.enablePaths": ["supabase/functions"]
```
