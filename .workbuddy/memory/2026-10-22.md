## 🔴 修掉两个坏掉的 git 钩子（环境级，影响 10-20 之后所有提交）

`.git/hooks/pre-commit` 与 `pre-push` 都被换成了**指向临时目录的软链接**：

```
.git/hooks/pre-commit -> /var/folders/.../T/boh-prepush-zfunyE/scripts/git-hooks/pre-commit
```

`boh-prepush-*` 是 `npm run prepush` 的临时 worktree，跑完即删 ⇒ 软链成死链。
git 对「存在但不可执行」的钩子会**静默跳过**（不报错、不阻断），所以
2026-10-20 16:40 之后的提交（16:48 / 16:51 / 10-22 08:55 三个）**全都没跑 lint-staged**，
prettier/eslint --fix 一次都没生效，也没人发现。

修法（已执行）：`cp scripts/git-hooks/pre-commit .git/hooks/ && chmod +x`（pre-push 同）。
**待办**：把「钩子是不是死链」加进 `npm run env:doctor`，否则下次还会被临时 worktree 换掉。

## 决策：竖屏体检脚本放 `docs/demos/` 而不是 `scripts/probes/`

`probe-portrait-adaptive-audit.mjs` → **`docs/demos/portrait-adaptive-audit.mjs`**。

两条理由：
1. 它**不做断言**（只输出数值 + 截图、不设退出码）⇒ 按 `docs/demos/README.md` 的
