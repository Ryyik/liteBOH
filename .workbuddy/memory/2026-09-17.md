## 活动页重构方案 · 关键设计洞察（产出 `plans/008-activities-page-restructure-insights.md`）

需求：活动页顶部放**活动报名卡**，其下改为**按月份分组的横向滚动卡片区**。只做洞察梳理，未动代码。

### 真库实测（REST 直查，非推断）

| 表 | 行数 | 结论 |
|---|---|---|
| `activities` | 17 | `date` 是 **varchar(50)**，无 stage / 无报名 / 无时间窗字段 |
| `activity_campaigns` | **0** | 表结构在线但**无数据** → 现有 `campaign-section`（`v-if`）**线上永不渲染** |
| `activity_entries` / `_rewards` | 0 | 同上 |

**campaigns 为何是 0 行**：`2026090901_probe_seed.sql` 插的 `probe-test-campaign` 被 `2026090902_probe_cleanup.sql` 删了 → 探针 seed 用完即清。
连带结论：`probe-campaign-ui.mjs` 的 `check("进行中活动区块出现")` **当前跑必然 FAIL**。

### `activities.date` 三态脏数据（月份分组的真正障碍）

- `YYYY/M/D` 9 条（`2026/2/3`）· `YYYY/M` **6 条缺「日」**（`2025/10`）· `YYYY-MM-DD` 2 条（`2026-08-10`）
- **字符串切分必崩**：`split('/')[1]` 对 `2026-08-10` → `undefined`；`slice(0,7)` 对 `2026/2/3` → `2026/2/`
- **DB `order=date.desc` 是错的**（字符串比较）：实测 `'2025/7/21' > '2025/12/12'`、`'2026/2/3' > '2026-08-10'`（`'/'`0x2F > `'-'`0x2D）
- 前端 `new Date(date.replace(/\//g,'-'))` 重排**侥幸正确**（V8 把 `2024-7` 宽松解析成 `2024-07-01`，不报错 → 典型假绿）；且 ISO 分支走 UTC 08:00、斜杠分支走本地 00:00，**同字段两套时区语义**
- `2024/12/31` 有两条 → `sort` 不稳定，相对顺序会漂

### 其他缺口（顺带发现）

- **RLS 与注释不符**：`activity_campaigns_select ... using (true)` → **draft 对 anon 可读**，但 `activities-platform-api.js:25` 注释写"由 RLS 兜底"。草稿过滤只在 API 层。
- **报名状态 N+1**：`ActivitiesList.vue:122-141` 每卡一次 `getMyCampaignEntries` → 12 活动 12 次往返，API 层无批量接口。
- **两表无关联键**：`activities.id`(bigint) vs `campaigns.id`(uuid)/`slug`，**fulfilled 活动没有归档通道**（`ForumMain.vue:2349` 只能靠 title 字符串匹配）。

### 推荐方向

1. **报名卡读 campaigns**（自带 stage/signup 窗口/entries 唯一约束），历史区读 activities —— **不做统一 list**（时间语义相反）
2. SQL 走**生成列**（`event_date date generated always as (...) stored`）+ `activity_timeline` 视图（算 `month_key` / `month_ord`），**不动历史数据、不触发 `sync_official_forum_card`**
3. 组件拆到 `ActivitiesWall/components/`（`check:structure` 规则：`src/views` 顶层禁单文件页面）
4. 横滑范式抄 `Forum/styles/feed.css:632-653` 的 `.image-post-strip`（**露边负 margin 需按新容器 padding 反推，不能照抄**）

### 易踩点

- `ActivitiesWall/index.vue:127-147` 的 `:deep()` 补丁在类名变更后**静默失效**（不报错）
- `--aw-nav-h`（外层）与 `--nav-h`（内层）**两套导航高度变量 + 两个 ResizeObserver** 干同一件事
- 详情岛三件套（`ContentDetailIsland` + `showIsland.custom` + `provide('remountWallIsland')`）必须原样保留，否则常驻岛永久消失
