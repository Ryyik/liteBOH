### 关键坑（都实测踩过）
1. **ForumMain TDZ（用户报「一点关注就报错」）**：
   `watch(() => props.externalFeed, cb, { immediate: true })` 同步调 `fetchForumData()`，
   而它是 800 行之后才声明的 `const` → ReferenceError → 整页被全局错误边界接管成「页面出了问题」。
   触发条件：点「关注 / 新闻 / 活动」（`latest` 因 early return 逃过）。修法：
   `void Promise.resolve().then(() => fetchForumData())`。探针 C4 六分区逐个点做回归。
2. **开场层不能靠「锁文档滚动」**：style.global.css 里 html/body/.home 都带 `!important`，
   想覆盖就得新增 `!important` → 撞 important-budget 棘轮（多 3 条直接红）。改用
   `.home-gate { position: fixed }`（与 .home 实际高度解耦），进入瞬间 `window.scrollTo(0, 0)`。
3. **分区页签被悬浮导航胶囊遮挡（用户截图报的）**：`.home-forum-stage` 曾写死
   `--segment-tabs-inset: 18px 20px 2px` → 「新闻/活动」被盖住。修法：不覆盖该变量，吃
   SegmentTabs 默认值；首页还要自己探测 `#unified-nav-container` 实测高度写 `--userspace-nav-h`
   （UserSpaceMain 有同口径逻辑，首页不经过它）。
4. 开场层一次性标记：`sessionStorage['boh-home-gate-passed']`；想重看动画删掉它再刷新。
