**为什么独立建而不复用 BohModal**：BohModal 是**模态**（滚锁 + 焦点陷阱 + 遮罩）。下拉**刻意不做**这两件 —— 边上有输入框/列表要能继续滚、焦点要能 Tab 出去。设计上划清了边界并在源码注释写明，防下批人「顺手补齐」。

**四个实测坑（前三个都是「探针全绿但画面错的」）**：
1. **焦点归还不能写在 emit 之后** —— 面板已进移除流程，`contains(activeElement)` 恒 false。
2. **`rAF` / `setTimeout(0)` 也不行** —— leave 过渡期间面板还在 DOM 里，焦点根本搬不走（日志：`el.isConnected=true` 而 `activeElement` 仍是面板项）。必须等 `Transition` 的 **after-leave**。
3. **after-leave 里不能直接 `focus()` 包裹层 `<span>`** —— span 不可聚焦、`focus()` 静默无效，必须 `querySelector` 找里面真正的按钮。**这条排查最久**，前两种时机其实都白试了。
4. **指示器会被 `overflow` 裁掉** —— 它 absolute 定在面板外 6px，面板写 `overflow-y:auto` 就整块消失，而「DOM 里有没有箭头」的断言照样绿。正解：面板 `overflow:visible` + 滚动挪进内层 `.boh-dropdown__scroll`。

## C 类第一步：壳第五口子 `morph` + 商品详情迁壳（plans/047）

**决策**：不把 C 类当「迁 3 份弹层」做。三份（`ShopAccountPanel` 已划掉：`mode="page"` 本身就是页面）卡在**同一个缺口** —— 壳只有「单列卡 + 淡入缩放」，它们要「任意几何 + 形变进出场」。形变原语被 5 个文件共用（PostDetailModal / ProductDetail / LotteryDetail / 两个 ImageViewer），改错代价高，**且失效时没有任何测试会红**。所以先单独一批补能力 + 补守卫，再迁宿主。

### 壳侧五处改动
1. 过渡名二选一 `morph ? 'boh-morph' : 'boh-pop'`。`boh-pop` 的 transition 带 transform，CSS transitions 在层叠里压过 WAAPI ⇒ 形变整段失效且无报错。
2. 新增 `boh-morph` 预设：**只声明时长、不动任何属性**（Vue 靠它算离场时长，否则节点下一帧就摘掉；但不能真去动 clip-path/opacity）。**不写毫秒兜底**（预设层纪律）。
3. `--morph` 类摘掉 dialog 的底/边框/圆角/阴影/backdrop（否则与宿主面板叠成双层外壳，形变时两块一起缩）。
4. header 条件加 `!morph` —— `showClose` 默认 true，即使 title 为空也渲染 52px 空头把面板撑高（实测 dialog 904 vs 面板 852）。
5. `defineExpose({ dialogRef })`。

### 第六条坑（方案原文没写到，本批实测）
**退场必须 `await` 几何播完再返回**。不在动画本身，在**卸载时序**：宿主常被父级 `v-if` 控制，`emit('close')` 让子树**立即**卸载，实测节点 **8ms** 就被摘除、一帧没跑（用户看到「硬切消失」）。壳的 `<Transition>` 写了离场时长也保不住。

### 三个额外实测坑（迁商品详情时）
1. **`min-height:0` 让 grid 封面区塌成 56px** —— grid item 允许收缩到内容高度。必须显式 `grid-template-rows: minmax(0,1fr)` 并去掉 `min-height:0`。
2. **`.is-landscape .detail-surface` 写成后代选择器永远不匹配** —— 两个类在**同一个** `<article>` 上，必须 `.is-landscape.detail-surface`（无空格）。表现是**双列静默退回单列 flex、右栏文字被挤到 0 高**，内容断言全绿、只有截图看得出来。同一文件里我曾并存两套 `.is-landscape` 规则（尺寸 + grid）互相冲突，已合并。
3. 域 token 必须挂宿主自己的面板上（壳的 overlay 不是宿主后代，scoped 够不着）—— 与 OrderDetailSheet 那条同一结论。

### 探针写法三条坑（`probe-boh-morph-surface.mjs`）
1. **`getComputedStyle().clipPath` 读不到 WAAPI 中间值** —— 第一版采样器全程读到 `none`，我据此误判「形变没播」，实际动画在跑。必须走 `el.getAnimations()` 读关键帧与 offset。
2. **采样器要与点击在同一个 `evaluate` 里启动** —— 分开写时前 20 帧全在点击之前跑完，采到一片 `n:0` 空帧。
3. **`page.evaluate` 不能直接接本地函数** —— 本探针把读动画逻辑串成源码常量再 `new Function('return ...')()`。

## 清债：probe-pd-modal 的 A6/A9 两条长红假断言

A8（上一节）暴露出的是一类系统性问题：**同一次「媒体满出血」改造留下的过时口径**，
红久了就被当「环境问题」跳过。这一批把剩下两条收掉，探针从 3 红 → **43/43 全绿**。

**A6（口径漂移）**：旧期望「媒体左/顶 16px、列间 18px」。改造后 `.detail-container`
`padding:0` + `gap:0`、内衬搬到 `.pd-modal-info` 的 `padding: 0 24px` ⇒ 旧值永不成立。

去掉内衬 → 红在 24px 那半；容器写回 16px → 红在 ≤2 那半（媒体实测 17px）。

**A9 的真因不是口径漂移，是「选错对象」，而且有三层**（这层是本次最有价值的发现）：
1. 旧判据 `!card.querySelector('.image-post-thumb')` 用的是**懒加载 img** —— 没滚进视口
   就不渲染，「没有缩略图」根本不能推出「无图帖」。
2. **广告位也带 `.post-card-v2` 类**（`ad-slot ad-slot-fixed`，实测 12 张卡里 2 张是它）。
   广告卡没有 post 属性 / 没有标题 / 没有缩略图 ⇒ 旧判据**优先命中广告卡**；
   随后 `clickCardAt` 按索引去点 `.post-title-v2` 的第 N 个，而广告卡里没有标题，
   **索引错位到别的帖子**上 ⇒ 打开一条有图帖，却断言「无媒体区」，必然红且红错原因。
3. 关闭后不等 overlay 真正移除就开下一条，`waitForInPage` 第一次轮询读到**残留旧面板**
   （实测出现 `panelW:760` 与 `infoLeftGap:565` 这种自相矛盾读数）。

三处全修：判据换 `image-post-card-v2`（由 `post.hasImages` 驱动，与懒加载无关）
+ 显式 `:not(.ad-slot)` + 关闭后 `waitForFunction(() => !overlay)`。
断言改「无媒体区 + 无 has-media + info 铺满整格 `|infoW-(panelW-2)| ≤ 4`」
（旧式子的 `-32` 是改造前的 16px×2 内衬）。输出带上「目标帖 id / 实开 id」，

`.lintstagedrc.json` 是 `{ "*.{js,mjs,vue,ts}": [...] }` —— **它按暂存区（`git diff --cached`）跑，
不看你 `git commit -- <路径>` 限定了什么**。所以只要并行会话把它的文件 `git add` 进了暂存区，
即使我提交时只写自己的路径，钩子仍然会把那些文件一并带进本次提交。
**正确做法：提交前先 `git diff --cached --name-only` 看暂存区全貌**，把不属于本次的文件
`git restore --staged <路径>` 移出（只移出暂存区，工作区改动不受影响），再提交。
本次就是这样做的：暂存区原有 6 个文件（含并行会话的 `probe-settings-redesign-demo.mjs` /
`useSettingsChrome.js` / `SettingsSubpageHeader.vue`），移出后剩 3 个，钩子日志显示
「2 files」而非更多，`git show --stat` 也确认干净。
