### 二、审查发现并修复的三处**实证**缺陷（9fbb9ae5）

每条都先写会失败的测试 → 修 → 反证（改回原样必须红）。

**① 长对话活动行整条消失**（`BohChatStream.vue` activityHostIdx）
返回 `props.messages.length - 1`（可见列表内下标），而模板 `idx` 是**全局下标**
（`visibleMessageItems` = `slice(start).map((o) => index: start + o)`，`start = total - 80`）。
只在 ≤80 条时相等 —— 正是当时所有单轮探针的口径。超 80 条后 v-if 永不命中 ⇒
发问题头顶没有等待动画，且**不报错**。修：返回条目自身 `index`。
守卫 `bohai-activity-host-index.test.js`(5)。

**② 小方卡在「思考」不再动**（pet-bus 单例只写不清）
岛是 `v-if="rendered"` **关岛即卸载**，流式中途关岛后 watch 停住，'thinking' 永久
留在单例 ⇒ `busy` 守卫拦死自主动作 + 睡眠判定永不成立 + 角色一直画思考态。
修：两个写入方（BohChatStream / BohIslandAnswer）卸载体 `setPetStage('')`；
BohChatStream 只在 unmounted 复位（deactivated 时流还在跑）。
守卫 `bohai-pet-bus-lifecycle.test.js`(7)。

**③ plans/044 声称「阶段 0 已落地」实则三项都没接上**
- `dedupe.js` 仍留 150 行**逐字重复**实现（plan 说的是 re-export）⇒ 两份真源。已改 re-export。
