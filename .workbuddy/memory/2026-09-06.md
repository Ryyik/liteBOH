## vite build 与 WorkBuddy node shim 冲突解法（重要长期经验） (2026-09-06 深夜)
- 现象：vite build 反复在 prepareOutDir（SAFE_DELETE_BULK_CONFIRM_REQUIRED，清空 dist/static 469+ 文件需确认）或 rollup writeOutputFile（"Brokered host mkdir requires an available runtime file rule"，新建子目录被拦）失败。transform 阶段（✓ 3073 modules）始终正常——编译问题与 shim 问题要区分开。
