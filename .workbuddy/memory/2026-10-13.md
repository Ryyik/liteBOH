### 三、本轮踩到/沉淀的坑（会咬人的）

1. ⚠️ **过渡 + 自测量 = 自锁**：给 textarea 的 `min-height` 加 transition 后，`scrollHeight` 会把「自身当前高度」算进去 ⇒ 展开↔还原的过渡中途量到半途值（实测 77px）被 `useAutoGrowTextarea` 原样写回成 inline 高度，框**永久停在 77px**。高度必须瞬时切换，只让颜色/圆角过渡。
2. ⚠️ **源码计数断言必须先剥注释**：一条解释性注释里复述 `var(--boh-content-mr)` 就让计数 4→5、断言红在注释上（`bohai-content-column` 已改为 `stripComments` 后再数）。
3. ⚠️ **探针判据别依赖文案**：`probe-bohai-keepalive-stream` 原先用「页面文字里还有『内容由 AI 生成』」判「是否还在 AI 页」⇒ 文案一删判据即失效，已改**结构判据**（`.boh-shell`）。
4. ⚠️ **`useAutoGrowTextarea()` 漏传 value getter = watcher 永不触发**（程序化清空/预填不回弹）。bohai-step7 撞 429 配额中断时留下这个缺陷，靠它自己写的单测抓住（`bohai-autogrow-wiring`），主 agent 一行修复。
5. ⚠️ **并行会话同文件纠缠**：`PostDetailMain.vue` 同时含另一会话在途改动（回复 @ 标签规则）。提交自己的 hunk 的可行做法：`git show HEAD:<path>` 取基线 → 脚本重放自己的改动生成干净版本 → `hash-object -w` + `update-index --cacheinfo` 暂存 → 提交后再把工作树文件还原（对方 hunk 保持未暂存）。**不要**用 `git add -A` / 不要整文件提交。
6. ⚠️ **多 agent 共享 pre-commit 钩子会扫入他人暂存文件**：一次实测中 lint-staged 把另一 agent 暂存的 `BOHAIMain.vue` 卷进提交；修法是 `reset --soft HEAD~1` + `restore --staged <侵入文件>` + 用路径式 `git commit -F <msg> -- <paths>` 重提。每次提交后**必须** `git show --stat HEAD` 核对。
