### 二、沉淀「重构验证协议」`docs/重构验证协议.md` + `npm run compare:builds`

**核心命题**：拆分类重构的失效是**静默的**（没报错、没测试红，只是样式不生效或事件没人接），所以只跑 `verify` 不够。协议给了 **L1–L6 六层**，每层都写明**能力与盲区**：

| 层 | 工具 | 证明什么 | 证明不了什么 |
|---|---|---|---|
| L1 静态 | `npm run verify` | 语法/类型/结构/预算 | 跨文件字符串契约、产物一致性 |
| L2 单测 | （含在 verify） | 被断言的行为 | 没被断言的路径 |
| **L3 产物** | `npm run compare:builds` | **证明「纯搬运」**（声明级逐条比对） | 运行时行为、视觉 |
| **L4 配对** | （含在 L3 工具） | CSS scope id ↔ JS scope id 配对 → 排除「样式静默不生效」 | —— |
| L5 运行时 | `scripts/probes/*` | 真实交互 | 探针未覆盖的路径 |
| L6 人眼 | 无 | —— | **必须明示为人工步骤** |
