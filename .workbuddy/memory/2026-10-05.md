### 发现并修复：5 个 Dependabot PR 的 CI 全红
`gh run list` 里 5 个 Dependabot PR（3 个 actions 版本升级 + 2 个 npm 依赖组更新）的
`CI Quality Gate` 全是 failure。`--log-failed` 根因一致：**`Error: supabaseUrl is required`**。

根因（GitHub 硬机制）：**Dependabot 触发的 workflow 读不到 repository secrets**，
只能读 Dependabot 专属的那一套。核对：
- `gh secret list --repo Ryyik/liteBOH` → 7 个（含 VITE_SUPABASE_URL / ANON_KEY）
- `gh secret list --app dependabot --repo Ryyik/liteBOH` → **空**

修复（值取自本地 `.env`；两者本就是可公开的前端配置，`ci.yml` 注释亦如此声明）：
```
set -a && . ./.env && set +a
printf '%s' "$VITE_SUPABASE_URL"      | gh secret set VITE_SUPABASE_URL      --app dependabot --repo Ryyik/liteBOH
printf '%s' "$VITE_SUPABASE_ANON_KEY" | gh secret set VITE_SUPABASE_ANON_KEY --app dependabot --repo Ryyik/liteBOH
```
⚠️ **改 secrets 不会自动重跑已有 run** —— 必须 `gh run rerun <id>`。
重跑 5 个 run（37227027541 / 37212534622 / 37212329130 / 37212335640 / 37212342029）→ **全部 EXIT=0**；
最终 `gh pr checks` 五个 PR 全 pass。
