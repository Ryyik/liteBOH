### 顺手挖出的真 bug：排序键错了（用户报「日期似乎有点错误，图片顺序不太对」）

`listMyCloudEntries` 用的是 `.order('updated_at', { ascending: false })` —— **按最后编辑时间排**。
症状：**编辑一条旧内容，它会跳到最前面**，看起来就是日期顺序错乱。

修：改主排序为 **内容日期** `.order('entry_date', { ascending: false, nullsFirst: false })` + 次排序 `updated_at desc`；
legacy 回退 `listLegacyNotesAsCloud`（老表列名 `note_date`）同口径。

⚠️ 三条判断依据：
- **必须在服务端排**：查询带 `limit(240)`，客户端再 sort 只能对已截断的那一页排，会真的排错。
- **`nullsFirst: false` 必写**：PostgreSQL 在 DESC 时默认 NULLS FIRST，不写会把「没填日期」的条目全顶到最上面。
- 只改 `listMyCloudEntries`（+ legacy 回退）。`listUserPublicCloudEntries`（作品格）与
  `getMyCloudEntriesForAI` 未动 —— 不在本次报障范围，避免连带影响别人的展示。

### 五条实测坑（已写进 AGENTS.md / PROBES.md）

1. **多图摊平的 key 必须带下标**（`${entry.id}::${index}`）：只写 `entry.id` 会让同一条目的多个格子撞 key，
   Vue 复用节点时**串图**。
2. **列数要由 JS 算、CSS 只消费 `--album-columns`**：早期用 CSS `auto-fill` 自适应，但
   auto-fill **没法被手势覆盖** —— 横屏（Mac 触控板捏合）就无从调节。改成
   `resolvedAlbumColumns = 用户选择 ?? 视口自动`（窄屏固定 5 列、宽屏按格宽 ~130px 推列数）。
3. **捏合是阶梯不是连续映射**：每跨过阈值就重置基线，一次张手可连切 5→4→3；阈值 1.25 / 0.8。
   `touchmove` 必须**非 passive** 才能 preventDefault（Vue 的 `@touchmove` 默认非 passive，别加 `.passive`），
   宿主还要 `touch-action: pan-y`（放行单指滚动、其余手势交给 JS）。
4. **列数测量用 ResizeObserver**，不能只监听 `window.resize`：图库页宽屏是铺满的，
   从设置页切回内容页时容器宽度会变而窗口不 resize —— 只监听 window 会留下错的列数。
5. **探针必须清 localStorage 起点**：列数会落盘，上一轮跑出的 4 列会被读回来，让「竖屏 5 列」断言假红。

### ⚠️ 过程中自己造成又自己抓回的一个事故（教训值很高，别删）

改 `listLegacyNotesAsCloud` 的排序时，写 Edit 的 old_string **漏掉了中间那行**
`.eq('user_id', safeUserId)`，于是替换后**用户过滤整行消失** —— 排序写对了，
但那个 legacy 回退查询会拉出**所有用户**的笔记。

三件事：
1. **是 lint 抓到的**：`'safeUserId' is defined but never used`。这个仓库的 unused 警告
   不只是死代码提示，它还能兜住「Edit 时少抄了一行」。所以 verify 的 183 棘轮别当噪声看。
2. 已补一条守卫单测（`cloud-album-order.test.js`）：统计 `.eq('user_id', safeUserId)`
   出现次数 ≥ 2，少于就红 —— 把「漏用户过滤」从一个要靠人眼发现的问题变成会当场变红的断言。
3. **改 Multiple-line Edit 的纪律**：old_string 必须**完整覆盖**要动的每一行（含夹在中间的
   不变量，如 where 子句），否则「只改排序」会顺手删掉条件。宁可比对长一点。

## 第六轮：滑动闪烁 + 详情弹窗四连修

用户报障「滑动的体验不流畅，内容一直在闪烁」+ 详情弹窗三问（白条 / 关闭按钮不固定 / 「设为公开」语义）。

### 滑动闪烁：诊断探针证明 DOM 零变动、帧率 60fps → 是**渲染策略**问题，三个修复

1. **相册网格去掉 `TransitionGroup` + 逐格错峰**：26+ 格上做 FLIP move（transform 0.4s），
   且 `--item-index` 逐格延迟（30 格 × 0.04s = 首屏连续淡入 1.2s）—— 这就是「一直在闪烁」。
   iOS 图库的格子也是直接出现，改回普通 div。
2. **touchmove 改为「两指期间动态注册」**：常挂非 passive touchmove 会让浏览器每帧
   等 JS 判断完才敢滚动，单指滑动整体被拖慢。现在 touchstart（passive）里检测到两指才
   `addEventListener('touchmove', fn, { passive: false })`，touchend 即拆。
3. **图片 `eager` → `lazy` + RO 宽度早退**：RO 观察的是 section，图片陆续加载改的是**高度**，
   回调里不做宽度早退就是「每张图加载 = 一次强制同步布局」。

### 详情弹窗（4 个问题同一处）

| 报障 | 根因 | 修法 |

| 顶部异常白条 | `.detail-overlay { padding-top: 64px }` + `modal height: calc(100% - 64px)` —— **顶层与 ≤640 媒体查询各写了一份**，只改顶层会被媒体查询吃回来（实测 64px 生效中） | 两处都改：overlay 不留带、modal 全屏 |

`.liquid-glass`」是同一类坑：**同名的第二处定义永远会赢**。
