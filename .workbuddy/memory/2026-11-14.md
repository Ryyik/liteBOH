## 底栏收起态改造：下滑收成左下圆 / 上滑或点击展开（已实现，dev 预览中）

用户口径：底栏是玻璃胶囊；下滑自动缩到左边，上滑展开，点击也能展开；缩成球时发帖 `+` 跟着降下来对齐；球要小。

### 落地

- `UserSpaceBottomNav.vue`：`navHidden` 拆成 `is-collapsed`（滚动收起，仍在）/ `is-hidden`（键盘、消息选择态，真消失）；新增 `.nav-compact` 面（当前席图标 + 未读点，`aria-label`），收起时 `.nav-items` 挂 `inert`；emit `expand-request`，四个宿主（首页 / 我 / 周边 / 图库）都接 `resetBottomNavAutoHide`。
- `bottom-nav.css`：收起只动 `width`+`height`（`left` 钉死 ⇒ 天然左锚）+ 5 席 90ms 先退场、圆图标 120ms 后入场。新增 `--bottom-nav-item-h / -item-min-w / -compact-size(60) / -expanded-w / -morph-ms / -morph-ease`；居中档（700–1024）改成「显式宽度 + `left: calc(50% - W/2)`」，因为 `width:auto` 无法过渡。
- `useScrollDirectionHide.js`：阈值 20/8 → 24/12 + 220ms 冷却；**`reset()` 不再清 positions**（清掉会让「点开圆之后第一条 scroll 只当基线」，表现为要滑两下才收）。
- `compose-fab.css`：`body.boh-bottom-nav-collapsed`（由底栏组件唯一写入，FAB 是 Teleport 到 body 的兄弟节点）→ embedded FAB `bottom:144 → 22`，22 = 球 60 高、底 20 的球心 50 − FAB 半高 28。
- `user-space-dark.css`：球内图标 `#f8fafc`、收起态投影（带 `!important`，否则被暗色玻璃投影压住）。

### 三条踩过的坑（下次直接引用）

1. **`height: auto` ↔ 长度不可过渡**。所以展开态高度由 JS 量一次写进 `--bottom-nav-shell-h`；只用 `getBoundingClientRect` + 挂 `resize`，**不能用 ResizeObserver**（收起动画全程尺寸在变，RO 会把中间态写回去形成自激）。
2. **圆直径不能由条高反算**：条高是内容撑的（icon 17 + gap 3 + 标签行高 22.8 + padding 14 + border 2 = 75）。现在球固定 60，宽高都走过渡，所以严格相等。
3. **暗色 CSS 是懒加载的**（`theme-css-loader`）：探针里手工改 `data-theme` 读到的仍是明色，必须写 `localStorage['boh-theme']='dark'` 让 themeManager 自己切。

## 切页「闪一下」与唤岛「卡一下」（同日第二轮，已修）

### ① 切页闪：路由级 200ms 淡入已移除

- 实测（PerformanceObserver + 逐帧采样 `.route-fade-enter-*`）：**每一次跨路由切换**都给整页加了一次
  opacity 0→1；而缓存页 DOM 本来就是复用的（`probe-cloud-keepalive` 0 请求），等于主动闪一下。
  深色页上是「从透明闪出底色」，浅色页上是内容先消失再浮现。
- 处理：删掉 `App.vue` 的 `<Transition name="route-fade">` + `style.css` 里的 `.route-fade-*`
  （2026-11-04 加的 P0-1 那版，它自己的注释就写着「不生效的最坏表现 = 退回瞬切」）。
- 复测：三次切换 `fadedCount=0`；`图库→我` 的 scrollY 从 0 恢复成 600（顺带修好了回顶）。
- ⚠️ **`/`（首页）与 `/shop` 仍不在 keepAlive 白名单**，每次进都是重挂 + 8 次请求（探针 D 组实测）。
  这两席要不要一起缓存是产品口径问题（首页常驻 30s 轮询会变成后台轮询），未擅自改。

### ② 唤岛卡：三个结构性原因

- **RO 每帧重入**：开岛时 surface 高度在 300ms 里逐帧变化 ⇒ nav 的 ResizeObserver 每帧回调
  `measureTop`，而它内部是「读 rect → 写 class/变量 → 再读 rect」= 每帧 2~3 次强制同步布局。
  改成 `scheduleMeasure()`（rAF 合并）+ 动画窗口 `morphUntil` 内让路 + 末尾补一次尾测。
- **mount 任务里 3 次强制布局**：`measureTop` 里卡片的 `getBoundingClientRect` 提到**所有写操作之前**
  一次读掉（profile：`getBoundingClientRect` 38.8ms/70 次）。
- **键盘与长高动画并发**：`BohIslandAnswer.onMounted` 立刻 `input.focus()` ⇒ iOS 键盘弹起 + 视口变化
  + 岛 max-height 重排全叠在同一帧。改为 **340ms 后**再聚焦（= 300ms 长高动画 + 余量）+ `preventScroll`；
  `UnifiedNavbar` 的 focusInput 兜底同基准（只是兜底，不抢跑）。
- 复测（6× CPU 降速，rAF 帧间隔）：长任务从 2 个（67~100ms）降到 1 个（69~71ms）；**4× 降速下长任务 0 个**。
  剩下那一个是回答面 UI 的挂载成本，要再降只能做两段式挂载（先壳后内容），未做。

`probe-nav-ask` 29/29、`probe-route-switch` 通过（opacity 全 1）、`probe-cloud-keepalive` 全绿、eslint 0 error。

## 底栏五席全部进 KeepAlive（用户拍板「首页+周边都缓存」）

- `router/routes/public.ts`：`/` → `HomePage`、`/shop` → `ShopPage`（`meta.keepAlive + keepAliveName`）；
  两个组件补 `defineOptions({ name })`（名字不一致会**静默不缓存**，`keep-alive-names.test.js` 逐字校验）。
- **Shop 的收尾必须从 onBeforeUnmount 挪到 onDeactivated**（这次最容易漏的一条）：
  它的 `onBeforeUnmount` 里有 `bagStore.flushShoppingBag()`（购物袋落盘）、
  `detachAvatarMenuGuards()`（document 级 pointerdown 守卫）、`unlockPageScroll()`、抖动排序态。
  缓存后「离开 ≠ 卸载」⇒ 不挪的话：加购后点底栏切走会丢袋、守卫会跟到别的页面继续拦点击。
  现在抽成 `teardownTransient()`，`onDeactivated` 与 `onBeforeUnmount` 共用；
  全局监听 / 导航高度观察器在 deactivate 摘、activate 重挂（用 `hasActivatedOnce` 闩锁跳过首次）。
- 两页都加 `onActivated(() => resetBottomNavAutoHide())`：回来见到的应该是整条底栏，不是一颗球。
- 探针 `probe-cloud-keepalive` 的 D 组反转（首页必须**复用**），反证换成 `/gift`（非白名单，必须重建）；
  新增 F 组（周边复用）。8 组全绿：五席来回切都是同一实例，`/gift` 仍重建。
- ⚠️ 首页缓存代价（已告知并接受）：帖子流 30s 轮询在离开后仍在后台跑；回来看到的是缓存内容。
- ⚠️ 周边分区**不记忆**：底栏「周边」落点是裸 `/shop`，`handleNavClick` 显式回「产品」——既有口径，未动。
