### 关键踩坑记录（重要）

1. **`position: sticky` 在 `overflow-x: hidden` 的父容器里会失效**
   `.hk-page { overflow-x: hidden }` 导致 `.hk-topbar` 和 `.hk-compact` 的 sticky 全部塌陷。
   解决：`.hk-topbar` 改 `position: relative`（普通文档流）；`.hk-compact` 改
   `position: fixed; top: var(--hk-nav-h); left:0; right:0; z-index:18`。

2. **Teleport 到 body 的组件会丢失 CSS 变量作用域**
   `HkSheet` 用 `<Teleport to="body">`，而所有 `--hk-*` 变量声明在 `.hk-page` 上，
   导致表单内 `var(--hk-blue)` / `var(--hk-text)` 全部取不到值。
   解决：变量块选择器写成 `.hk-page, .hk-sheet-mask`（布局规则仍只给 `.hk-page`），
   深色模式同理 `html[data-theme="dark"] .hk-page, html[data-theme="dark"] .hk-sheet-mask`。

3. **内联 `:style="{ color: tier.color }"` 中 CSS 变量字符串不生效**
   变量定义在 `.hk-page` 作用域而非 `:root`，`getComputedStyle(documentElement)` 取不到。
   解决：改为 class 切换（`.is-thin/.is-normal/.is-over/.is-obese/.is-empty`）。

4. **SVG 圆环 `stroke-linecap="round"` 在零长度 dash 上仍渲染端点**
   无数据时露出小圆头。解决：进度 circle 加 `v-if="hasValue"`。

5. **Sheet 的"黑色遮罩 + 内容被遮挡"问题根因**
   - 黑遮罩：`.hk-sheet-mask` 的 `background: rgba(12,14,22,0.28)` + `backdrop-filter: blur(18px)`，
     它是 `position: fixed; inset:0; z-index:99999` 的全屏层 → 改为 `background: transparent` 并移除 backdrop-filter。
   - "遮挡"：命中测试显示全部控件 `isSelf: true`，并无真实层叠覆盖；真正原因是 `.hk-sheet`
     沿用了 `.hk-card` 基类的 42% 半透明玻璃底，页面彩色 orb 光斑透出来造成脏污错觉
     → 给 `.hk-sheet` 单独设 94%→88% 不透明渐变底 + `blur(40px) saturate(200%)` + 更实的 box-shadow。
   - 深色模式补 `rgba(58,58,60,0.96) → rgba(28,28,30,0.94)`。

### 全局导航安全区
`UnifiedNavbar` 是 `position: fixed; z-index: 9999`，高度 72 / 64 / 60 / 54（横屏≤1024 / 竖屏≤768 / 竖屏≤480）。
页面侧用 `--hk-nav-h` 变量 + `.hk-page { padding-top: var(--hk-nav-h) }` 留位。

### Playwright 冒烟测试注意
playwright 自带 chromium 版本缺失，必须 `chromium.launch({ channel: 'chrome' })` 用系统 Chrome。
诊断遮挡用 `document.elementFromPoint(cx, cy)` 命中测试 + `getComputedStyle` 扫描全屏 fixed 层，很有效。
