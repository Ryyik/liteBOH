**决策表核心结论（用户问过「是不是都用注释删」）**：注释法**只在 CSS 选择器块场景占优**（构建永不报错，唯一有效信号是视觉截图比对）。整文件必须 `git rm`（注释后仍被 lint/tsc/glob/门禁扫到，且注释版残留本身即新死代码）；文件内片段直接删；需要"禁用试跑"时用 `git mv X X.disabled` 而非注释。**注释法解决的是"信息不足"，不是"更安全"**——A 级候选直接删 + 全套门禁 + git 回滚，比先注释跑一轮少一个来回且信号不减。
⚠️ CSS **不能嵌套注释**：待注释块内若已有 `/* */` 会在第一个 `*/` 提前闭合。动手前 `grep -c '/\*' <file>`。

**脚本实现要点（复用时的关键）**：`supabase/functions/**` 必须列为入口（Edge Function 独立部署、平台按路径调用，否则 19 个函数全报孤儿）；keyframes 必须在「全部 css + 全部 vue style」合并语料里计数（只看模板得 295/320，真值 15/320）；`<style>` 块要从使用语料剔除（否则 vue 内定义的类自我匹配）。

### editor_sdk（tencent-local-office-edit）可复用事实
- `get_pool_status` 在 `present_files` 后可能仍为空 → 直接 `open_file ... open_with_existing=true`，返回的 `file_id` 就是**路径字符串本身**，后续编辑工具可一直用该路径当 file_id。
- `save_file` **必须显式传 file_path**：实例若由 `open_file` 建立（非前端 open），服务端没登记原始路径，会报 `file_path is required`。
- 删多段用 `doc_delete_paragraph idx=<段起始>`，**从后往前**传原始 start_index 即可，前面段的坐标不受影响；文档最后一段不可删。
- `doc_insert_html_content` 支持 `style="font-family:黑体;font-size:14pt;text-indent:2em;line-height:1.5;text-align:justify;margin:0"`，一次写入 24 段全格式正确（font-family/font-size/line-height/text-align 生效）；**唯一没生效的是 text-indent**——`2em` 按 12pt 算出 24pt，字号不同的标题（14pt）应得 28pt。修法：再用 `doc_modify_paragraph` 传 `first_line_indent_chars:2` + `jc` + `line_spacing:1.5` + `line_spacing_rule:1` + `spacing_before/after:0`（这几类可同包），按 标题/正文/图注 分 3 组调用。
- **坑：editor_sdk 保存会丢嵌入字体**（`word/fonts/*.odttf`、`word/_rels/fontTable.xml.rels`、fontTable 里的 `w:embedRegular/embedBold`、[Content_Types].xml 的 odttf Default 全部消失，styles.xml/numbering.xml 也会被重生成）。补法：以新包为基础，从原包拷回 `word/fonts/*` + `word/_rels/fontTable.xml.rels`，用原包对应的 4 个 `<w:font>` 块（含 r:id 与 fontKey）替换回去，再给 [Content_Types].xml 加 `<Default Extension="odttf" ContentType="application/vnd.openxmlformats-officedocument.obfuscatedFont"/>`；`settings.xml` 的 `embedTrueTypeFonts` 本身会保留。补完用 `open_file` + `doc_resolve_document_structure` 复验（能开且节点数/坐标不变即 OK）。
- 换包时**不能只换 document.xml**：新包的 `word/_rels/document.xml.rels` 里 rId 映射与旧包完全不同（rId1=settings vs rId1=customXml），必须 document.xml 与 rels 成对替换。
