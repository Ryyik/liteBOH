**新学到的仓库规则（踩了才想起来）**：
- 🔴 根目录新增 `*-demo.html` 会被 `check:root-clean` 拦（棘轮：html 22 + 临时脚本 3）。
  正确落点是 **`docs/demos/`**，别放根目录再抬基线。
- 🔴 `check:doc-truth` 用 `git ls-tree HEAD` 计数（**不是工作区、也不是 index**）⇒
  「新增脚本」与「改 AGENTS.md 数字」**必须同一个提交**，否则先后顺序永远有一边红。
  这次靠「提交时不跑 pre-commit（本机 .git/hooks 未安装）」才一次过；若装了钩子会卡住，
  届时正确做法是分两次提交（第二次只改数字）。
- 探针里 `elementFromPoint` 量隐藏面板的圆标会得到假红（rect 全 0）⇒ 必须先
  `getClientRects().length > 0` 过滤可见元素。
