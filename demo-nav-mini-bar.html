竖屏导航 · Mini Bar 形态方案

默认 MINI 胶囊（logo + 头像 + 汉堡）⇄ 点击展开为现状长条。直接在左边手机上操作：点胶囊、点汉堡、滚动页面、点空白处。

MINI ⇄ EXPANDED + MENU ISLAND

操作入口

回缩策略（可开关，直接感受差别）

交互规则

  • 展开：点 mini 胶囊任意空白处 / 点汉堡。logo 和头像保留直达（首页 / 我的方块），不触发展开——单手最常用的两个目标保持一步可达。
  • 汉堡：mini 态 = 仅展开长条；长条态 = 开菜单（备选：mini 态点汉堡直接展开+开菜单，一步到位，待拍板）。
  • 锚点不动：morph 中 logo icon 与头像位置恒定，只有中间文本「生长」，无元素跳位。
  • 岛卡仲裁：任意岛型弹出——通知卡 / 任务卡 / BOHAI AI 岛 / 自定义岛（详情卡、分享卡等）——一律强制 EXPANDED（岛需要全宽锚点）；岛收回后自动回 MINI（菜单开着则保持长条）。
  • 未登录：mini 态 = logo + 登录按钮 + 汉堡，规则不变。

动画规格

  • 宽度 158px → calc(100% - 16px)，500ms --ease-emphasized（项目既有 token）；spacer flex-grow 0→1 同曲线，天然可动画。
  • 文本 max-width 0→96px + opacity，展开延迟 90ms 进场、回缩即时先出；圆角恒 100px。
  • 菜单/岛卡沿用现有玻璃卡规格（top 66px、radius 18-20px），只在展开态可开。
  • prefers-reduced-motion → 直切无动画。

实施落点（确认后）

  • UnifiedNavbar/index.vue：navMini 状态 + 竖屏 media query 监听 + 展开/回缩事件（外点/滚动/空闲定时器/岛卡联动）。
  • UnifiedNavbar/style.scoped.css：MINI 形态与 morph 动画；vendor unified-nav.css 不动。
  • 业务逻辑零改动（汉堡/菜单/头像跳转原样）；探针 + 反证验证（撤掉 mini class 确认断言变红）。
