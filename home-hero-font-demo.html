生产接入要点（与《实施交付说明》A2 一致）

① 自托管：npm i lxgw-wenkai-lite-webfont，把按 unicode-range 切分好的 woff2 + css 复制到 public/fonts/lxgw/（本 demo 走 jsdelivr 仅便于预览，生产不走第三方 CDN）。
② 加载纪律：font-display: swap；字体 CSS 不得进入首屏 render-blocking 链；只 preload 问候语覆盖的 1~2 个分片。
③ 使用范围：仅展示层（问候 / 下滑提示 / 官方 tab 海报标题）；正文一律系统栈，中文正文上 web 字体是包体灾难。
④ 失败兜底：'LXGW WenKai Lite','Kaiti SC','STKaiti','KaiTi',serif——加载失败回落系统楷体，气质相近、页面完整（顶部第三个按钮可模拟）。
⑤ 可读性：图上文字区加 scrim（黑 12%~25% 渐晕），对比度 ≥ 4.5:1；prefers-reduced-motion 下呼吸动画停用。
