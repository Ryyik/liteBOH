# Voss — 创意设计师 / 创意开发者作品集模板

**模板分类**：作品集（Portfolio）  
**目标用户**：数字设计师、交互设计师、创意开发者  
**技术栈**：React 18 + TypeScript + Vite + React Router + GSAP/ScrollTrigger  
**默认语言**：页面内容中文，配置与说明中文。

---

## 1. 设计定位

模板以“克制的科技感、实验性的动态排版、有节奏的作品展示”为核心：

- **色彩**：纯黑背景（`#000000`）+ 灰白文字（`#F3F2EF`）+ 冰蓝强调色（`#2E5BFF`）。
- **字体**：Space Grotesk（标题/字标，OFL）+ Inter（正文，OFL）。
- **三种统一动效**：
  1. 首屏完整姓名字标（方块之家 BOH，末词冰蓝）遮罩分段入场 + 滚动退场。
  2. Studies 横向轨道，以及 Selected Work 标题悬停时的逐字上卷。
  3. 链接与按钮的微交互。
- **响应式策略**：桌面 Studies 为固定视口 + 滚动驱动的横向滑动；手机改为原生横滑 + 纵向项目流，保证标题、入口、联系信息始终可见。

## 2. 功能清单

- 完整首页：导航、首屏字标、Studies 横向画廊、Selected Work（7 个项目）、About、Capabilities、Contact。
- 首屏海报墙：打开页面时海报以字标附近为焦点、由近及远逐张浮现，并压平到同一块倾斜平面上，约 2 秒内成墙；随后墙面开始缓慢漂移。继续下滚四屏，海报散开飞向镜头（景深虚化与光谱色散），结束后释放滚动进入 Studies。减弱动态时回退为静态封面网格。
- 七个内容不同的案例详情页（可独立访问、刷新、返回）。
- Studies 在 Selected Work 之前，最多展示前 5 个项目封面；1440×900 桌面下每张图片为 630×420。滚动到该模块时左侧说明文字淡出到约 75% 时图片轨道即从屏幕右侧外自动滑入（无需继续滚动、无需停顿）：入场 3 秒，使用手工调校的自定义贝塞尔 `bohRoll (0.36, 0.02, 0.28, 1)`——慢起步、中段加速、尾段长而软的滑行停稳，不用标准命名缓动；入场完成后页面纵向锁定，向下滚动继续驱动轨道从右向左滑动，滑完后才释放进入下一模块。整个画廊使用一个 WebGL 画布，图片中间部分保持平直，仅在屏幕左右两端产生卷曲、拉伸、玻璃高光与光谱色散；透镜固定在视口两端，入场与滚动时都是内容通过透镜，不再给每张图片描边。透镜画布按运动速度自适应采样与内部分辨率（快速移动时降采样降分辨率，静止时满质量重绘），保证入场与滚动期间的帧率。仅在滚动、缩放或重新进入可见区域时重绘。
- Selected Work 为“左侧标题列表 + 右侧粘性封面预览”：7 个标题左对齐，悬停或键盘聚焦时标题逐字符上卷并变为冰蓝色，右侧预览同步淡入该项目的封面（纯画面，无图注、无阴影）；点击标题或预览进入案例详情。
- 手机端 Studies 使用原生横向滑动（scroll-snap），不启用 pin。
- 手机端 Selected Work 改为纵向列表：标题下方直接显示对应封面，不加载右侧粘性预览。
- 页面切换冰蓝遮罩过渡，防止快速点击锁死。
- 自定义指针（仅精确鼠标设备），不影响触控与键盘。
- 邮箱复制按钮，真实成功后提示。
- 键盘焦点、Esc 关闭菜单、焦点恢复、`prefers-reduced-motion` 支持。
- 返回首页时恢复滚动位置。

## 5. 安装、运行、构建与预览

```bash
cd voss-portfolio
npm install
npm run dev          # 开发服务器，默认 http://localhost:5274
npm run build        # 类型检查 + 生产构建，输出到 dist/
npm run preview      # 预览构建产物，默认 http://localhost:5274
```

交付包 `voss-portfolio.zip` 内含完整源码、依赖配置（`package.json` / `package-lock.json`）、`dist/` 静态构建产物、`screenshots/` 验收截图与 `LICENSES/` 授权说明；不含 `node_modules/`、密钥、真实用户数据或任何部署绑定。解压后 `npm install` 即可开发与构建；`dist/` 可直接由任意静态服务器托管，但需为 React Router 配置回退到 `index.html`（SPA 模式），否则案例详情页刷新会 404。

## 6. 如何替换为个人品牌

1. 打开 `src/content/site.ts`。
2. 修改 `site` 对象：姓名 `name`、字标 `monogram`（首屏整词排版，建议填完整姓名或短词）、定位 `role`、地点 `location`、邮箱 `email`、社交链接 `socials`。
3. 修改 `projects` 数组：标题、分类、年份、角色、文案、图片路径。
4. 在 `public/images/` 中替换图片，保持建议比例：封面 4:3 或 3:2，详情图 3:2。
5. 调整 `motion` 对象即可改变全局动画时长与缓动，无需进入组件。
6. 颜色、间距、字体在 `src/styles/global.css` 的 `:root` 变量中调整。

## 10. 已知限制

- 模板为纯前端静态站点，案例内容在 `site.ts` 中维护；如需 CMS/MDX 支持需自行扩展。
- 自定义指针仅在 `(pointer: fine)` 设备启用；触控设备使用系统指针。
- 七个案例项目均为虚构演示内容，所有数据、客户与结果均为占位，不可作为真实业绩引用。
- Studies 的图片纹理上传一次，整排在滚动和尺寸变化时实时重绘；离开可见区域后停止绘制。浏览器禁用 WebGL、纹理加载失败或上下文丢失时保留原生图片与滑动；上下文恢复后重新初始化透镜。
- 两端折射固定在画廊视口，而非跟随每张卡片；中间图片不加玻璃边框。效果为独立实现，使用本模板自己的图片与排版。
- 粘性预览使用 `position: sticky`，要求父级没有 `overflow: hidden`；二次开发时请保留 `.work-stage` 的网格结构。
