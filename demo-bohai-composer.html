4落地映射 · 对现有代码的改动面

这版设计是在 plans/023 已落地的 .composer-panel 上做形态调整，不改「模式决定模型」的口径。下面是对 BOHAIMain.vue 与相关真源的具体影响，供确认后再动代码。

设计元素现有实现改动
双环圆钮 .context-ring-wrap（单环）+ .context-tokens（旁边一个独立的今日 token 标签） 合并为一个 .usage-orb：外环 contextBudgetUsage.historyPercent，内环今日额度百分比。删除独立的 token 标签。
用量浮层 点 token 标签 → openQuotaPanel() 打开侧栏 AiQuotaSidePanel 改为就地浮层，两个数字同屏可对比。侧栏保留，作为浮层里「用量详情」的入口。
分档配色 ringColorClass（已按 level 分档） 口径沿用，扩展到两条环各自分档：<55% 主色 / 55–85% 琥珀 / >85% 红。
模式胶囊 .composer-panel-trigger（SlidersHorizontal 图标 + 模式名 + 下箭头） 去掉左侧图标，改为 模式名 + 强度 两段文字（极速 中），强度用灰色弱化，更短更轻。
主面板 .composer-panel：第 1 组「模式」平铺列表 + 第 2 组「思考强度」平铺列表 两组各压成一行：模式 › / 推理强度 ›，加一条分隔和 高级 ⌃。面板从两组高列表变成三行。
二级菜单 无（两组都是就地平铺单选） 新增左右两个 .submenu。模式列表向左、推理强度向右弹出，避免遮挡输入框。选中态沿用现有 .active + 勾。
模式项信息 模式列表项带 tagline 副标题 + 倍率 / 免费角标 副标题收进二级菜单项，列表只留 模式名 + 倍率角标 + 勾，贴近参考图的纯净列表。
高级开关 plans/023 已把 4 个工具开关放进面板第 3 组 收进「高级」折叠区，面板默认只露三行。开关本身不动。
好消息：这一版和 plans/023 不冲突了。023 §口径① 已经定案「模型选择就是模式选择，不新增独立模型选择器」， 所以本稿把参考图里的「模型」行换成「模式」行 —— 维度没变，只是形态从「两组平铺列表」改成「两行 + 二级菜单」。 落地时只在已落地的 .composer-panel 上做结构调整。
推理强度已定为三档（低 / 中 / 高），与现有真源 THINKING_SPEED_OPTIONS （chat-engine-config.js:252）一一对应（低 = low、中 = medium、高 = high），不需要动数据层。 参考图的第四档「极高」本次不采纳 —— 它要新增一份 deltas（temperature / topP / maxTokensScale） 并确认「更快消耗额度」的口径，留到以后再说。
