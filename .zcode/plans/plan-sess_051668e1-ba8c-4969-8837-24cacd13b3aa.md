# BOHAI 输入区 + 设置面板优化方案

已确认的四个决定：① 删掉的设置收进折叠「高级」；② 数据操作放面板底部一行小字；③ 上下文环从消息区搬进输入框（单一位置）；④ AiQuotaSidePanel 退役，入口统一到设置面板。

## 改动一：输入区（BOHAIMain.vue:584-753）

新布局：`[+号] [textarea] [上下文环] [思考] [模式] [发送]`

1. **上下文圆圈**：把 BOHAIMain.vue:373-428 的 SVG 环模板从 message-actions 搬进 `.input-right` 最左侧。计算逻辑（`ringProgress`/`ringColorClass`/`contextBudgetLabel`，1405-1416 行）不动直接复用。点击环 → `openSettings()`（用量卡就在设置面板里）；原 `.context-tokens`（今日 Token 标签）随旧块一起移除。≥80% 的 `.context-full-banner`（757-771）保留，message-actions 其余按钮不受影响。
2. **思考强度控件**：新增 `.composer-thinking-picker`，交互与模式选择器同款——按钮显示当前档（低/中/高）+ 弹出菜单三档带描述。数据直接用 BOHAIMain 已解构的 `currentThinkingSpeedId`/`thinkingSpeedOptions`/`setThinkingSpeed`（1121-1123 行），持久化走现有 `boh_ai_thinking_speed_v1`，**不改 THINKING_SPEED_OPTIONS 表值**（不触发行为变更）。外点/Esc 关闭复用模式菜单的现有 pattern。
3. **CSS**：新控件样式对齐 `composer-mode-button` 的 34px 高度体系（adaptive-layout.css）；767px 竖屏媒体查询（1337 行起）补 32px 缩小规则、思考按钮窄屏只留图标；暗色覆盖进 full-workspace.css（如需）。

## 改动二：设置面板重组（BohaiSettingsPanel.vue）

7 分区 → **3 张卡 + 折叠「高级」+ 底部数据行**：

1. **卡1 个性化（记忆）**＝现有记忆分区（170-223）；「自动附加页面/识别选中文本/上下文模式」三行挪进高级折叠。
2. **卡2 订阅层级（新做）**：当前档位（TIER_LABELS 中文标签）+ 权益摘要（PLAN_AI_TOKENS 单源）+ 升级按钮（跳 `/user-center/subscriptions`）。逻辑从 AiQuotaSidePanel.vue:100-141 抽成共享 composable（新小文件，或扩展现有 useUserTier.js，实现时按契合度定），不抄第三份。
3. **卡3 用量**＝现有使用情况分区（247-290），并把 AiQuotaSidePanel 的联网搜索配额仪表并进来；`ai-settings-quota-overview` 等测试标记全部保留。
4. **高级**（默认折叠）：快捷入口（原样）+ 默认行为剩余项（回答风格/发送方式/默认联网/详情入口/默认响应模式）+ 外观（原样）+ 记忆区挪来的三行页面上下文。思考速度从面板移除（已搬 composer，避免双入口）。
