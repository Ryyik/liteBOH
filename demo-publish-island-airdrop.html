设计方案（对标 Apple Airdrop）

常驻规则：发帖后立即返回列表，岛从 idle 小药丸 弹簧展开为 busy 卡片，发送中不自动消失，持续显示缩略图+进度环百分比，直至 success 弹跳对勾 1.4s 后收起；failed 常驻至用户操作（重试/移除该图/取消），避免信息丢失。

  • 动效：`clip-path inset` + `transform translateY/scale` 420ms cubic-bezier(.16,1,.3,1)，入场带 4px blur，进图弹簧 `.34,1.56,.64,1`，符合 Airdrop 抛物线。
  • 材质：`background rgba(255,255,255,.96) + backdrop-filter blur 20px + inset 1px 白边`，阴影 `0 16px 48px rgba(0,0,0,.14)`，与 `GlobalNavStatusCard.vue:82` 同层。
  • 缩略图：单图 44px 圆角 12px；多图 3 张堆叠（-4°/5°/0°，白边 2px，阴影），与 Airdrop 文件堆一致；纯文则用渐变圆头像占位。
  • 进度：右侧 34px 圆环 `stroke-dasharray 62.8`，`stroke #1677ff → #00b578`，中心 `pct 10px 800`，文案区 `正在发送 · 42%`（不暴露压缩/检测细节，环+百分比双重反馈）。
  • 成功：环→对勾 `scale 0→1.15→1` 弹簧，背景切回黑底 `#1d1d1f`，1.4s 后 `clip-path inset 0 0 100%` 收起。
  • 失败：网络失败红底 `!` + `重试` 黑钮；审核不通过橙底 `!` + `移除该图` 橙钮（与乐观卡第2张红框 `审核未过` 联动，`fixModeration` 移除后进度 -10% 重试）。
  • 多任务：岛仅显示队头，标题自动叠为 `正在发送 2 条…`，列表内乐观卡顶部 3px 进度条 `scaleX(--p)` 同步。

交互时序

点发布 → 乐观卡插入 `forumData.unshift` + 岛弹簧展开（缩略图+环）→ 后台流水线 `compress 0→30% → moderate 30→58% → upload 58→100%` 仅映射为环百分比 → 成功：环→对勾→岛收起，卡 `发送成功 → 刚刚` → 失败：岛切橙/红常驻，卡显示对应失败条

与现有代码映射

ForumPublishIsland.vue `Teleport #unified-nav-container` 读取 `forumPublishQueue` 队头；ForumMain.vue:handlePost 改为入队即清屏；processPublishImagesForQueue 的 `setProgress` 驱动岛环与卡条。
