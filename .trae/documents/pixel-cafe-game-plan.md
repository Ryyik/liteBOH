# 像素咖啡馆 (PixelCafe) - 界面开发计划

## 一、项目定位

**PixelCafe** 是 BOH 网站的一个独立娱乐页面，以咖啡店为主题的卡通像素风格交互式界面。当前阶段**仅实现视觉效果和界面框架**，不包含游戏玩法逻辑。

**核心体验**：可爱的像素风咖啡店场景 + 响应式界面框架 + 横屏/竖屏适配

---

## 二、技术方案

### 2.1 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 框架 | **Vue 3 + Composition API** | 与现有项目一致 |
| 渲染 | **HTML5 Canvas 2D** | 绘制像素风场景 |
| 动画 | **CSS3 动画 + @vueuse/motion** | 项目已有依赖 |
| 状态 | **Pinia** | 界面状态管理 |
| 图标 | **lucide-vue-next** | 项目已有 |
| 响应式 | **CSS Media Queries** | 横屏/竖屏适配 |

**零新增 npm 包**，全部使用项目已有依赖。

### 2.2 包体积

- 路由懒加载
- 精灵资源程序化绘制为主

---

## 三、设备适配方案

### 3.1 屏幕方向策略

| 设备 | 方向 | 适配方案 |
|------|------|----------|
| **电脑端** | 横屏 | 主布局，完整场景 + UI 面板 |
| **平板** | 横屏 | 与电脑端类似，元素适当缩小 |
| **手机端** | **强制横屏** | 竖屏时显示"请旋转设备"提示遮罩 |

### 3.2 竖屏遮罩

检测到 `window.innerWidth < window.innerHeight` 时：
- 全屏遮罩 + 旋转手机图标 + "请横屏体验"提示
- 背景模糊，旋转回横屏后自动恢复

### 3.3 分辨率适配

- **游戏画布**：固定逻辑分辨率 960×540（16:9），CSS `transform: scale()` 等比缩放
- **断点**：
  - `≥1024px`：电脑端
  - `768px~1023px`：平板
  - `<768px`：手机端横屏

## 四、视觉风格

### 4.1 美术风格：Cozy Pixel（温馨像素）

- **基础精灵**：32×32 像素单位
- **边缘**：`image-rendering: pixelated` 硬边缘
- **配色**：

```css
:root {
  --cafe-wood: #8B6F47;
  --cafe-cream: #F5E6D3;
  --cafe-coffee: #6F4E37;
  --cafe-green: #7A9E7E;
  --cafe-gold: #D4A574;
  --cafe-pink: #E8A0BF;
}
```

## 六、实现步骤

### 阶段 1：基础架构

1. **创建目录结构**
   - `src/views/PixelCafe/` 及子目录

2. **路由配置**
   - `src/router/routes/public.js` 添加 `/pixel-cafe` 路由（懒加载）

3. **基础页面框架**
   - `index.vue`：容器，包含 TopBar、GameCanvas、BottomBar
   - `PortraitOverlay.vue`：竖屏检测遮罩
   - 基础 CSS 变量和像素风格初始化

### 阶段 2：Canvas 场景渲染

1. **Canvas 容器**
   - `GameCanvas.vue`：响应式 Canvas，自动缩放适配
   - `useCanvasRenderer.js`：渲染上下文、图层管理

2. **场景绘制**
   - 地板网格（程序化绘制）
   - 墙壁、窗户
   - 吧台、桌椅（基于配置数据渲染）
   - 装饰元素（植物、灯具、挂画）

3. **精灵系统**
   - 简单像素精灵数据结构
   - `drawSprite()` 绘制函数
   - 程序化绘制为主

### 阶段 3：UI 组件

1. **TopBar.vue**
   - 标题 "PixelCafe" + 咖啡图标
   - 设置按钮（装饰性）

2. **BottomBar.vue**
   - 状态提示文字（装饰性）
   - 几个像素风格按钮（装饰性）

3. **PixelButton.vue**
   - 像素边框风格
   - hover/active 状态

### 阶段 4：动画与打磨

1. **CSS 动画**
   - 咖啡蒸汽飘动
   - 植物轻微摇摆
   - 灯光微光

2. **Canvas 动画**
   - 顾客 idle 浮动

3. **响应式适配**
   - 各断点布局调整
   - 触摸设备优化
