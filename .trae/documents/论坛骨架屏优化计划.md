# 论坛骨架屏优化计划

## 项目背景
- **目标文件**: `/Users/ryyik/Documents/BOHLITEForMacLatest/BOHLITEBeta2.5/src/views/Forum/index.vue`
- **样式文件**: `/Users/ryyik/Documents/BOHLITEForMacLatest/BOHLITEBeta2.5/src/views/Forum/style.scoped.css`
- **核心功能**: 论坛帖子列表展示、加载状态显示

## 现有加载状态分析

### 当前实现
1. **加载状态变量**: `isLoading` (初始加载), `isLoadingMore` (加载更多)
2. **当前加载UI**: 简单的spinner动画 + 文字提示 "正在同步方块世界的数据..."
3. **加载更多UI**: 底部spinner + "正在加载更多帖子..."

### 当前问题
- 加载时只显示spinner，用户体验不够流畅
- 没有骨架屏效果，内容突然出现会有闪烁感
- 与现代化UI设计趋势不符

---

## 优化方案

### 阶段1: 创建骨架屏组件

#### 1.1 帖子卡片骨架屏
模拟帖子卡片的结构：
- 头像占位符（圆形）
- 用户名占位符（短条）
- 时间占位符（短条）
- 标题占位符（长条）
- 内容占位符（多行）
- 操作按钮占位符（小圆点/短条）

#### 1.2 创建骨架屏动画效果
- 使用CSS shimmer动画（从左到右的渐变流动效果）
- 背景色使用浅灰色系
- 动画循环播放

### 阶段2: 修改Vue模板

#### 2.1 替换现有加载状态
将现有的：
```vue
<div v-if="isLoading" class="loading-state-v2">
  <div class="loading-spinner-v2"></div>
  <p class="loading-text-v2">正在同步方块世界的数据...</p>
</div>
```

替换为骨架屏组件：
```vue
<div v-if="isLoading" class="skeleton-feed">
  <div v-for="n in 5" :key="n" class="skeleton-post-card">
    <!-- 骨架屏内容 -->
  </div>
</div>
```

#### 2.2 添加加载更多骨架屏
在底部加载更多时也显示骨架屏效果

### 阶段3: CSS样式实现

#### 3.1 骨架屏基础样式
- `.skeleton-feed`: 骨架屏容器
- `.skeleton-post-card`: 单个帖子骨架
- `.skeleton-avatar`: 头像占位
- `.skeleton-line`: 文字行占位
- `.skeleton-title`: 标题占位
- `.skeleton-content`: 内容占位

#### 3.2 Shimmer动画
```css
@keyframes shimmer {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}

.skeleton-item {
  background: linear-gradient(
    90deg,
    #f0f0f0 25%,
    #e0e0e0 50%,
    #f0f0f0 75%
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
}
```

### 阶段4: 响应式适配

#### 4.1 移动端骨架屏
- 调整骨架屏尺寸适应小屏幕
- 减少同时显示的骨架屏数量（3个 instead of 5个）

#### 4.2 桌面端骨架屏
- 保持与帖子卡片相同的布局
- 显示5个骨架屏卡片
