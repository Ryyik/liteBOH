# 像素咖啡馆 - 开发计划

## 项目概述
创建一个卡通像素风格的交互式咖啡馆应用，用户可自定义形象，选择座位（前台、窗边卡座、沙发），并与咖啡馆中的NPC进行互动。

## 技术栈
- Vue 3 + Composition API
- TypeScript
- CSS3 + CSS 动画
- HTML5 Canvas (用于像素渲染)
- Pinia (状态管理)

## 功能模块

### 1. 像素风格渲染系统
- **像素画布组件**: 使用 Canvas 渲染像素风格的咖啡馆场景
- **像素精灵系统**: 角色、家具、装饰品的像素精灵
- **动画系统**: 角色行走、坐下、互动等动画

### 2. 场景布局
- **咖啡馆主场景**: 
  - 前台区域（吧台、咖啡师NPC）
  - 窗边卡座区（靠窗的高脚桌椅）
  - 沙发休息区（舒适的沙发和茶几）
  - 装饰元素（植物、挂画、灯具等）

### 3. 角色自定义系统
- **角色编辑器**:
  - 发型选择（多种像素发型）
  - 肤色选择
  - 服装选择（上衣、裤子/裙子）
  - 配饰选择（眼镜、帽子等）
- **角色状态**: 站立、行走、坐下、互动等

### 4. 座位交互系统
- **座位选择**:
  - 点击座位进行选择
  - 角色自动移动到选定座位
  - 坐下动画和状态切换
- **座位状态**: 空闲、已占用（用户）、NPC占用

### 5. NPC系统
- **NPC角色**:
  - 咖啡师（前台）
  - 顾客NPC（随机分布在座位）
- **互动对话**:
  - 点击NPC触发对话
  - 对话气泡UI
  - 简单的对话树

### 6. UI界面
- **顶部导航**: 返回、设置按钮
- **角色编辑入口**: 自定义形象按钮
- **对话面板**: NPC对话显示
- **座位提示**: 悬停显示座位信息

## 页面结构

```
src/views/PixelCafe/
├── index.vue                 # 主页面
├── style.scoped.css          # 页面样式
├── components/
│   ├── PixelCanvas.vue       # 像素画布主组件
│   ├── CharacterEditor.vue   # 角色编辑器
│   ├── DialogueBox.vue       # 对话气泡
│   ├── SeatSelector.vue      # 座位选择UI
│   └── NPCDialogue.vue       # NPC对话面板
├── composables/
│   ├── usePixelRenderer.ts   # 像素渲染逻辑
│   ├── useCharacter.ts       # 角色管理
│   ├── useNPC.ts             # NPC管理
│   └── useSeat.ts            # 座位管理
├── assets/
│   └── sprites/              # 像素精灵图
│       ├── characters/       # 角色精灵
│       ├── furniture/        # 家具精灵
│       └── decorations/      # 装饰精灵
└── types/
    └── index.ts              # TypeScript类型定义
```

## 实现步骤

### 阶段1: 基础架构
1. 创建页面目录结构和基础文件
2. 添加路由配置
3. 创建TypeScript类型定义

### 阶段2: 像素渲染引擎
1. 实现Canvas像素渲染组件
2. 创建基础精灵绘制系统
3. 实现场景分层渲染（背景、家具、角色）

### 阶段3: 场景构建
1. 绘制咖啡馆背景（地板、墙壁、窗户）
2. 添加家具精灵（吧台、桌椅、沙发）
3. 布置装饰元素

### 阶段4: 角色系统
1. 实现角色编辑器UI
2. 创建角色自定义状态管理
3. 实现角色精灵渲染（根据自定义选项）

### 阶段5: 座位交互
1. 实现座位区域检测
2. 添加角色移动动画
3. 实现坐下/站起状态切换

### 阶段6: NPC系统
1. 创建NPC角色和位置
2. 实现NPC对话系统
3. 添加简单的AI行为（随机移动、 idle动画）

### 阶段7: 优化完善
1. 添加音效（可选）
2. 优化动画流畅度
3. 响应式适配
4. 性能优化

## 设计风格

### 像素艺术风格
- **分辨率**: 16x16 或 32x32 基础精灵
- **配色方案**: 温暖的咖啡馆色调
  - 主色: #8B6F47 (咖啡棕)
  - 辅色: #D4A574 (拿铁色)
  - 强调: #E8D4C4 (奶泡色)
  - 背景: #FFF8F0 (暖白)
- **视觉特点**: 
  - 清晰的像素边缘
  - 有限的调色板
  - 复古游戏感

### UI风格
- 像素风格的按钮和面板
- 圆润的像素字体
- 复古游戏UI元素

## 路由配置

```javascript
{

  name: "PixelCafe",
  component: () => import("../views/PixelCafe/index.vue"),
}
```
