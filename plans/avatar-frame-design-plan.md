# BOH 个性化头像框设计规划

> 对齐当前五档订阅体系（Free / Plus / Pro / Max / Ultra）的个性化头像框专项规划。
> 本文档只做设计与运营规划，不含代码实现。基于 2026-09 代码现状调研。

---

## 0. 现状对齐（规划的事实基础）

| 档位 | 价格（积分/月） | 定位 | 昵称色（代码映射） | 订阅页文案 |
|------|----------------|------|--------------------|------------|
| Free | 0 | 日常使用 | 无色 | — |
| Plus | 8 | 效率升级 | 蓝色 `nickname-blue` | — |
| Pro | 20 | 专业创作（最受欢迎） | 银色 `nickname-silver` | 写的"金色昵称" ⚠️ |
| Max | 40 | 全能尊享 | 金色 `nickname-gold` | 金色昵称 ✅ |
| Ultra | 70 | 研究级无限 | 彩虹 `nickname-rainbow` | 彩虹昵称 ✅ |

关键结论：

1. **头像框的视觉语言必须与昵称色同源**。用户已在论坛、评论区、签到日历、抽奖岛等处看到蓝/银/金/彩虹昵称，头像框若另起一套色系会造成识别混乱。建议昵称色 = 框的主色锚点。
2. ⚠️ **发现一处文案与代码不一致**：订阅计划页 Pro 档文案写"金色昵称"，但代码映射 `pro → nickname-silver`。立项时需统一（改文案或改映射），头像框按最终结论对齐。
3. 头像在列表页大量以 **xs/sm 小尺寸（约 24–36px）** 出现，框的设计必须通过 24px 可辨识测试。
4. 商店已有 **"BOH 装饰"品类**（勋章、贴纸、海报等），头像框作为数字装饰可自然挂入该品类。
5. 头像 URL 已有统一出口（`getAvatarUrl`，支持 sm/xs 尺寸），头像框可作为独立叠加层渲染，不动头像本身链路。
6. 等级数据已有现成 RPC（单查 + 批量，5 分钟缓存），头像框的"谁能用什么框"判断可直接复用，不需要新建真相源。

## 1. 设计方向

### 1.1 主推方向：萌宠猫狗系「毛孩俱乐部」🐾

**核心概念**：把 BOH 的 AI 伙伴拟宠化，每一档解锁一位"常驻毛孩"，用项圈/铃铛颜色暗合档位色阶，形成"集齐一窝"的收集欲。

| 档位 | 毛孩 | 框上元素 | 与昵称色的呼应 |
|------|------|----------|----------------|
| Free | 纸箱猫 | 默认细描边框（平权款，不强调付费） | 灰描边 |
| Plus | 布偶猫 | 蓝色项圈 + 小铃铛，猫耳从框顶冒出 | 蓝 |
| Pro | 银渐层猫 | 银灰围脖 + 银铃铛，猫爪扒框 | 银 |
| Max | 金毛寻回犬 | 金色项圈 + 吊牌，狗耳垂在框侧 | 金 |
| Ultra | 三花猫 & 柴犬双拼 | 彩虹围巾环绕整框，头顶小光环 | 彩虹 |

设计理由：

- **猫狗是全年龄段最大公约数**，与产品"AI 伙伴"人设天然契合，也方便后续做宠物表情包、宠物周边（和商店实物装饰线打通）。
- 毛孩只在框上"探出局部"（耳朵/爪子/尾巴），不整只占框，**小尺寸下辨识度最高**。
- 天然支持**限定变体**：春节唐装猫狗、万圣节南瓜猫、夏日清凉装，运营节奏好排。

### 1.2 备选方向（可小流量 AB 或作为赛季轮换）

| 方向 | 一句话描述 | 适配档位 | 风险/成本 |
|------|-----------|----------|-----------|
| 果冻玻璃拟态 | 半透明糖色玻璃环，贴合现有液态玻璃体系 | Plus/Pro | 与主体系最协调，但易撞"系统默认感"，差异化弱 |
| 方块像素风 | 8-bit 像素猫狗/徽章，呼应"方块之家"品牌基因 | 全档 | 品牌契合度最高，像素在小尺寸下反而清晰，成本中等 |
| 星轨金属风 | 深空底 + 星座连线 + 金属细环 | Ultra 专属 | 高端感强，适合拉 Ultra 转化；绘制要求高 |
| 节气国风限定 | 二十四节气/传统节日纹样环 | 运营限定 | 上新节奏依赖运营排期 |
| IP 联名款 | 外部形象授权联名 | 限时活动 | 版权成本与法务流程重，长期项 |

**建议路径**：首发用猫狗系建立认知 → 第二赛季上像素风做轮换 → Ultra 追加星轨款做"档位天花板"稀缺感。

## 2. 素材获取方式可行性分析

| 渠道 | 单个成本 | 周期 | 版权确定性 | 风格可控 | 可行性结论 |
|------|----------|------|------------|----------|------------|
| 原创绘制（内部/约稿自绘） | 时间成本为主 | 长 | ★★★★★ 完全自有 | ★★★★★ | 质量上限最高，但若无专职画师则周期不可控 |
| 素材库（iconfont / Freepik / Flaticon 等） | 低（订阅制或单张） | 极短 | ★★☆ 需逐张核对商用授权 | ★★☆ | 撞款率高、风格难统一，**只适合 MVP 占位与内部评审**，不建议直接上线 |
| AI 生成 + 人工精修（Midjourney / 即梦 / SD） | 低 | 短（天级） | ★★★☆ 依平台条款（付费订阅商用需确认 ToS） | ★★★★（垫图 + 固定 prompt 模板可保系列感） | **主力方案**。批量出图快，但 AI 输出描边不均、边缘毛糙，必须人工矢量化精修 |
| 外包（站酷 / 特赞 / 约稿平台画师） | 约 ¥200–800/个（矢量头像框） | 1–3 周 | ★★★★☆ 合同约定 | ★★★★ | 质量与交付稳定，全套 5 档 + 2 限定预估 ¥3k–8k |

### 推荐组合策略（三步走）

1. **MVP 期（第 1–2 周）**：AI 生成 + 人工精修，先出 5 档各 1 款，跑通"解锁—穿戴—展示"全链路，验证用户是否真的在意这东西。版权上保留 prompt 记录与平台订阅凭证。
2. **正式期**：数据验证后，把佩戴率最高的 1–2 款送外包精绘（或内部原创）作为"门面款"，其余沿用 AI 管线按赛季上新。
3. **长期**：建立素材规范（见第 3 节），限定款走外包/联名，常规款走 AI 管线，素材库仅作灵感参考。

## 3. 绘制风格建议

### 3.1 线条

- **均匀闭合描边**：240×240 源稿下建议 3px 主描边，圆角连接（round cap/join），禁锐角。
- 毛孩元素（耳/爪/铃铛）允许 2.5–3.5px 微差描边制造层次，但同一框内粗细变化不超过一档。
- **小尺寸优先**：设计稿必须同时通过 240px（个人主页）与 24px（列表回复头像）两档目检，24px 下主轮廓仍需可辨。

### 3.2 配色

- **框体主色 = 档位昵称色**：Plus 蓝（对齐品牌蓝 `#0071e3` 系）、Pro 银灰、Max 金、Ultra 彩虹渐变环。
- **主体填充用低饱和奶油色系**（米白/奶黄/浅灰），重色只出现在描边、项圈、铃铛等点缀上——避免框喧宾夺主吃掉用户头像。
- **暗色主题必须出双版本**：暗背景下描边整体提亮（蓝可参考 `#2997ff` 一类亮阶），银灰在暗底需加对比，否则会"隐身"。两版都过暗色实测再验收。
- Ultra 彩虹环建议限定 4–5 色、按固定角度分布，避免杂色。

### 3.3 质感

- **扁平 + 轻高光/轻噪点**为基准；禁重投影、禁大面积渐变——与现有液态玻璃体系（弱玻璃、单源 token）打架。
- Ultra 档允许"微渐变 + 微光效"作为天花板特权，但光效半径克制。
- 动效预留：眨眼、铃铛轻晃、尾巴摆动等 1–2 秒循环小动效作为二期（APNG/Lottie），一期全部静态。

### 3.4 结构与交付规格（对设计/外包的要求描述，非实现）

- **框 = 环形主体 + 单点萌物元素**：萌物只允许出现在"框顶 12 点方向（耳朵）、框侧 3/9 点（爪子/垂耳）、框底 6 点（尾巴/吊牌）"三个锚位，禁止整圈高密度图案。
- **挖孔安全区**：头像为圆形裁切，框内径需预留约 6–8% 间隙，保证任何用户头像的主体（人脸）不被遮挡。
- 交付：**SVG 为源**（viewBox 240×240，中心透明挖孔直径约 168px），附 PNG @2x/@3x 备份；每款附 24px 缩小预览图供验收。
- 每档交付清单：静态框 ×1 + 暗色版 ×1 + 节日变体（后续赛季）+ 24px 预览。

## 4. 落地场景与触发条件

### 4.1 展示位置（按现有头像出现点枚举，含优先级）

| 优先级 | 场景 | 位置说明 | 展示形态 |
|--------|------|----------|----------|
| P0 | 论坛帖子卡 | 作者头像（sm）+ 回复楼层头像（xs） | 静态框，xs 下自动隐藏萌物细节只留环 |
| P0 | 帖子详情 / 评论区 | 楼层与嵌套回复头像 | 静态框 |
| P0 | 个人主页 | 大头像位 | **完整细节展示位**，此处可见动效与全部元素 |
| P1 | 用户空间（UserSpace） | 个人首页面板头像、社区 Tab、印象列表 | 静态框；资产面板新增"我的头像框"管理入口 |
| P1 | 关注 / 粉丝列表弹窗 | 列表小头像 | 静态框 |
| P2 | 签到日历、抽奖保底岛 | 打卡人小头像 | 静态框（低优先级，可后接） |
| P2 | 智能概览卡片 | 用户头像 | 静态框 |
| 不展示 | 官方账号 / AI 助手头像 | 使用官方专用框（自有体系），不与订阅框混用 | 官方框 |

### 4.2 获取与穿戴触发条件

| 触发点 | 行为 |
|--------|------|
| **订阅支付成功** | 订阅开通/升级成功弹层中同步"已点亮对应档头像框"，一键立即佩戴（转化动线最短处） |
| **Pro 免费试用开启** | 发放"试用限定"临时框（3 天有效期标识），到期自动回收——把试用权益可视化，制造升级动机 |
| **订阅到期** | 框自动置灰回收，但保留"已解锁历史"记录；续费即恢复，且历史款在个人主页可显示"曾经拥有"小徽章（钩子） |
| **手动穿戴** | 入口：用户空间 → 资产/装饰面板；个人主页点击自己头像。穿戴状态持久保存，换框即时全站生效 |
| **等级变更** | 升级自动解锁更高档框（不清空低档，已解锁的保留可选）；降级/到期只回收"当前档未持有"的框 |
| **赛季限定** | 活动期间完成指定行为（如连续签到 7 天、参与抽奖）解锁限定框，与积分商城"BOH 装饰"品类联动 |

### 4.3 显示规则汇总

- 他人头像框随头像渲染，**判断逻辑复用现有等级查询与缓存**，不新增逐头像请求。
- Free 档提供默认平权细描边框（或不显示框），避免"满屏付费感"劝退免费用户。
- 匿名/树洞类场景默认不展示头像框（保护匿名语境）。

## 5. 风险与验收清单

- [ ] 24px 小尺寸可辨识实测（论坛回复楼层）
- [ ] 暗色主题双版本全 surface 实测（不只个人主页）
- [ ] 框不遮挡用户头像主体（挖孔安全区抽查不同比例头像）
- [ ] Pro 档昵称色文案与代码映射不一致问题已统一
- [ ] 装饰层样式走全局 token，不新增 `!important`（现有预算门禁）
- [ ] AI 生成素材的商用授权凭证归档（平台订阅记录 + prompt 记录）
- [ ] 到期回收 / 续费恢复的状态流转在试用、升级、降级三条路径下验证
- [ ] 官方账号与订阅用户头像框视觉不混淆

## 6. 里程碑建议（不含排期承诺）

1. **M1 概念定稿**：五档毛孩设定 + 2 款备选方向小样（AI 出图）→ 内部评审
2. **M2 MVP 上线**：5 档静态框 + 解锁/穿戴/到期回收最小闭环 + 订阅成功弹层点亮动线
3. **M3 赛季运营**：首个节日限定款 + UserSpace 装饰面板完整化 + 动效版试点（个人主页）
4. **M4 扩展**：像素风第二赛季、Ultra 星轨款、商城联动售卖（积分兑换非订阅限定款）
